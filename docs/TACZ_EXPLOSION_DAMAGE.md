# TaCZ 폭발 피해

TaCZ 1.1.8의 기존 거리·엄폐 판정과 반경을 유지하고, 피해 전달 시 플레이어·봇·일반 엔티티에 같은 전역 배수와 무기별 배수를 적용합니다. 플레이어에게만 적용되는 Minecraft 난이도 보정과 TaCZ Tweaks의 PlayerDamage 보정은 TaCZ 폭발에 한해 제외합니다. 일반 총탄 피해는 변경하지 않습니다.

- 공통 기본 피해 = TaCZ가 계산한 거리 감쇠 피해 × 전역 폭발 배수 × 무기별 폭발 배수.
- 전역 설정 키는 기존 `explosionPlayerMultiplier`를 유지합니다. 기본값은 2이며 기존 서버 설정을 덮어쓰지 않습니다.
- 감쇠 전 설정 피해가 80이고 두 배수가 모두 1이면 최대 기본 피해는 모든 대상에서 80입니다. 전역 배수가 2이면 최대 160입니다.
- 거리·엄폐·대상 크기에 따른 TaCZ 판정, 방어구·저항·흡수·무적·팀/스폰 보호는 유지되므로 조건이 다르면 실제 체력 감소는 다를 수 있습니다. 아이템·장식물 등은 각 엔티티 고유의 파괴/피해 처리 규칙을 유지합니다.
- 다른 종류의 폭발은 기존대로 플레이어·봇에만 전역/무기 배수를 적용합니다.

구현은 TaCZ의 Entity.hurt 호출 인수를 TaCZ Tweaks보다 먼저 기록하고 공통 배수를 한 번 적용합니다. 플레이어 hurt 진입 시 같은 값을 복원하며 원래 DamageSource를 유지하여 GunsmithLib의 피해 태그와 공격자 정보가 보존됩니다. LivingHurtEvent에서는 이미 처리한 TaCZ 폭발에 배수를 중복 적용하지 않습니다.

게임 확인: 같은 위치·장비·효과 상태의 플레이어와 봇, 일반 생명체에 폭발을 가하고 난이도를 바꾸어 비교합니다. 전역/무기별 배수, 거리·엄폐, 스폰 보호도 함께 확인할 수 있습니다. 게임 테스트는 사용자 측에서 진행합니다.
