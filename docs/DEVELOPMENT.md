## 빌드·호환성 검증

### 빌드

Windows에서는 프로젝트의 `export-jar.bat`를 더블클릭하면 Java 17 JDK를 찾아 빌드·테스트한 뒤
설치용 JAR을 `dist` 폴더로 내보냅니다. 완료 또는 실패 메시지를 확인할 수 있도록 창을 유지합니다.
자동 실행에서는 `export-jar.bat --no-pause`를 사용합니다. Java 17을 찾지 못하면 `JDK17_HOME`을 설치 경로로 지정하세요.
파일명은 `gungang-realistic_1.20.1_u<업데이트번호>_<한국 날짜 yyMMdd>.jar`로 자동 생성됩니다. 예: `gungang-realistic_1.20.1_u40_261013.jar`. `version.properties`에 마지막 성공 빌드 번호를 보관하며 `build` 또는 `exportJar`가 성공하면 한 번만 증가합니다. `export-jar.bat`도 같은 규칙을 사용하고, 내보내기 실패·컴파일·테스트·개발 실행에는 번호를 증가시키지 않습니다. 같은 날 다시 빌드해도 u41, u42처럼 새 번호를 사용하며 날짜는 빌드 당일 한국 시간으로 자동 변경됩니다.

Forge가 밑줄이 들어간 모드 버전을 거부하므로 내부 모드 버전은 `40.261013` 형식을 사용하고, JAR 파일명에는 요청한 `u40_261013` 형식을 적용합니다. `version.properties`는 삭제하거나 이전 값으로 되돌리지 말고 소스와 함께 보관하세요. 이전 배포본은 보존하며 설치할 때는 이전 JAR를 제거하고 새 JAR 하나만 넣으세요.

```powershell
$env:JAVA_HOME='C:\Program Files\Java\jdk-17'
.\gradlew.bat build
.\gradlew.bat runClient
```

Linux/macOS에서는 Java 17 환경에서 `sh gradlew build`를 실행합니다. 최초 빌드는 Forge/Minecraft 의존성을 내려받습니다.

TaCZ를 함께 개발 실행하려면 공식 배포 파일을 `.cache/compat/tacz-1.20.1-<버전>.jar`에 넣은 뒤:

```powershell
.\gradlew.bat runClient '-PtaczVersion=1.1.8-hotfix2'
```

선택 의존성은 개발 실행 전용이며 배포 JAR에 묶이지 않습니다.

이 버전은 **FPS 플레이에 맞춘 기하 음향 근사 프로토타입**입니다. 부분 노출 판정은 신체 샘플에 의존하며 모든 픽셀의 가시성을 계산하지는 않습니다. 파동 방정식, 위상 간섭, 주파수 대역별 실제 재질 측정값,
다중 반사·실내 잔향, 여러 모서리를 도는 경로, 음속에 따른 지연과 정확한 수면 굴절은 구현하지 않았습니다.
우회 경로는 음량·필터에만 반영하며, 도달 방향은 원래 음원 방향을 유지합니다.

## 폰트 렌더링 구현

`config/gungang/fonts`에 TTF를 넣으면 파일명 순으로 첫 파일을 선택한다. `fontFile`에는 경로가 아닌
파일명만 지정할 수 있다. 외부 TTF를 읽고 형식을 확인한 뒤 메모리에 보관해 해당
리소스 재로딩 동안 같은 데이터를 제공한다. F3+T로 파일 추가·교체를 반영한다.
외부 글리프가 없으면 내장 Galmuri11 Bold 공급자를 사용하며, 읽기 실패 시에도 내장 폰트로 복원한다.

내장 Galmuri11 Bold 폰트는 논리 크기 9를 유지하면서 기본 6배 해상도로 글리프를 생성한다.
폰트 탭의 `fontOversample`로 1~8배를 선택하며, `fontSmoothing`으로 선형 필터링을
켜거나 끈다. 저장 시 리소스를 다시 불러오고 내장 팩의 폰트 정의를 설정값으로 생성한다.
이전 3배 설정에 비해 각 축의 해상도는 2배, 글리프 픽셀 면적은 약 4배이며,
사용하는 글자 수에 따라 폰트 아틀라스 메모리와 최초 글리프 생성 비용이 증가한다.

`FontTextureMixin`은 오버샘플링된 단색 글리프가 들어간 아틀라스에 선형 필터링을
적용한다. 새 글리프 업로드와 렌더 상태 변경 이후에도 필터를 유지한다.
컬러 비트맵 글꼴 아틀라스는 기존 필터를 사용한다. 리소스를 다시 불러오면
아틀라스와 필터 상태가 함께 재생성된다.

참고: [ModernUI-MC](https://github.com/BloCamLimb/ModernUI-MC)의 안티앨리어싱 및
고해상도 텍스트 렌더링 접근. 이 구현은 Minecraft의 기존 TTF 공급자와 배치 렌더링을
활용하며, ModernUI 코드나 의존성을 포함하지 않는다. ModernUI의 SDF 렌더러,
FreeType 힌팅, 화면 배율에 맞춘 동적 래스터화까지 구현한 것은 아니다.

수동 확인: GUI 배율 1~4에서 한글/영문 메뉴와 HUD를 비교하고, 새 글자를 채팅에
입력한 뒤에도 필터가 유지되는지 확인한다. F3+T와 사용자 지정 폰트 켜기/끄기 후
폰트 복원 여부를 확인한다. HUD 아이템 슬롯과 체력바의 빈 부분은 배경 월드가
약 50% 비치며, 테두리와 채워진 체력 부분은 불투명하게 표시된다.
