### Export 후 서버·클라이언트 자동 설치

`export-jar.bat`는 빌드 성공 후 `export-paths.json`의 `serverMods`, `instanceMods`에 지정된 mods 폴더를 업데이트합니다. 로컬 설정 파일은 Git에서 제외되며, 새 환경에서는 `export-paths.example.json`을 복사해 절대 경로를 지정합니다. 한쪽을 비우면 해당 대상은 건너뛰고, 설정 파일이 없으면 기존처럼 `dist`로 내보내기만 합니다. 서버와 Minecraft를 종료한 뒤 실행하세요.

이번 빌드의 정확한 파일명은 `dist/latest-export.txt`에 기록됩니다. 설치기는 파일명과 내부 mod ID가 GunGang인 기존 JAR만 교체합니다. 이전 파일은 각 mods 폴더의 `.gungang-backups/<고유번호>/`에 보관하며, 복사 오류가 나면 해당 폴더의 제거된 기존 파일을 복원합니다. 대상 폴더들은 순서대로 처리되므로 뒤쪽 대상이 실패해도 앞서 완료된 대상의 업데이트는 유지됩니다.

빌드 없이 마지막 내보내기 설치를 재시도하거나 변경 예정만 확인할 수 있습니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/install-exported-jar.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/install-exported-jar.ps1 -WhatIf
# 이전에 내보낸 특정 파일을 명시하려면 -JarPath "dist/파일명.jar" 추가
```

Gradle의 `exportJar`를 직접 호출하면 JAR 내보내기까지만 수행합니다. 자동 설치는 배치 파일 또는 위 PowerShell 스크립트를 사용하세요.

## 빌드·호환성 검증

### 빌드

Windows에서는 프로젝트의 `export-jar.bat`를 더블클릭하면 Java 17 JDK를 찾아 빌드·테스트한 뒤
설치용 JAR을 `dist` 폴더로 내보냅니다. 완료 또는 실패 메시지를 확인할 수 있도록 창을 유지합니다.
자동 실행에서는 `export-jar.bat --no-pause`를 사용합니다. Java 17을 찾지 못하면 `JDK17_HOME`을 설치 경로로 지정하세요.
파일명은 `gungang-realistic_1.20.1_u<업데이트번호>_<한국 날짜 yyMMdd>.jar`로 자동 생성됩니다. 예: `gungang-realistic_1.20.1_u40_261013.jar`. `version.properties`에 마지막 성공 빌드 번호를 보관하며 `build` 또는 `exportJar`가 성공하면 한 번만 증가합니다. `export-jar.bat`도 같은 규칙을 사용하고, 내보내기 실패·컴파일·테스트·개발 실행에는 번호를 증가시키지 않습니다. 같은 날 다시 빌드해도 u41, u42처럼 새 번호를 사용하며 날짜는 빌드 당일 한국 시간으로 자동 변경됩니다.

Forge가 밑줄이 들어간 모드 버전을 거부하므로 내부 모드 버전은 `40.261013` 형식을 사용하고, JAR 파일명에는 요청한 `u40_261013` 형식을 적용합니다. `version.properties`는 삭제하거나 이전 값으로 되돌리지 말고 소스와 함께 보관하세요. 이전 배포본은 보존하며 설치할 때는 이전 JAR를 제거하고 새 JAR 하나만 넣으세요.

```powershell
$env:JAVA_HOME='C:\Program Files\Java\jdk-17'
.\gradlew.bat build
.\gradlew.bat runClient
```

Linux/macOS에서는 Java 17 환경에서 `sh gradlew build`를 실행합니다. 최초 빌드는 Forge/Minecraft 의존성을 내려받습니다.

TaCZ를 함께 개발 실행하려면 공식 배포 파일을 `.cache/compat/tacz-1.20.1-<버전>.jar`에 넣은 뒤:

```powershell
.\gradlew.bat runClient '-PtaczVersion=1.1.8-hotfix2'
```

선택 의존성은 개발 실행 전용이며 배포 JAR에 묶이지 않습니다.

## 폰트 렌더링 구현

`config/gungang/fonts`에 TTF를 넣으면 파일명 순으로 첫 파일을 선택한다. `fontFile`에는 경로가 아닌
파일명만 지정할 수 있다. 외부 TTF를 읽고 형식을 확인한 뒤 메모리에 보관해 해당
리소스 재로딩 동안 같은 데이터를 제공한다. F3+T로 파일 추가·교체를 반영한다.
외부 글리프가 없으면 내장 GUNGANG → Galmuri11 Bold 공급자를 사용하며, 읽기 실패 시에도 내장 GUNGANG으로 복원한다.

내장 폰트(GUNGANG·Galmuri11 Bold)는 논리 크기 9를 유지하면서 기본 6배 해상도로 글리프를 생성한다.
폰트 탭의 `fontOversample`로 1~8배를 선택하며, `fontSmoothing`으로 선형 필터링을
켜거나 끈다. 저장 시 리소스를 다시 불러오고 내장 팩의 폰트 정의를 설정값으로 생성한다.
이전 3배 설정에 비해 각 축의 해상도는 2배, 글리프 픽셀 면적은 약 4배이며,
사용하는 글자 수에 따라 폰트 아틀라스 메모리와 최초 글리프 생성 비용이 증가한다.

`FontTextureMixin`은 오버샘플링된 단색 글리프가 들어간 아틀라스에 선형 필터링을
적용한다. 새 글리프 업로드와 렌더 상태 변경 이후에도 필터를 유지한다.
컬러 비트맵 글꼴 아틀라스는 기존 필터를 사용한다. 리소스를 다시 불러오면
아틀라스와 필터 상태가 함께 재생성된다.

참고: [ModernUI-MC](https://github.com/BloCamLimb/ModernUI-MC)의 안티앨리어싱 및
고해상도 텍스트 렌더링 접근. 이 구현은 Minecraft의 기존 TTF 공급자와 배치 렌더링을
활용하며, ModernUI 코드나 의존성을 포함하지 않는다. ModernUI의 SDF 렌더러,
FreeType 힌팅, 화면 배율에 맞춘 동적 래스터화까지 구현한 것은 아니다.

수동 확인: GUI 배율 1~4에서 한글/영문 메뉴와 HUD를 비교하고, 새 글자를 채팅에
입력한 뒤에도 필터가 유지되는지 확인한다. F3+T와 사용자 지정 폰트 켜기/끄기 후
폰트 복원 여부를 확인한다. HUD 아이템 슬롯과 체력바의 빈 부분은 배경 월드가
약 50% 비치며, 테두리와 채워진 체력 부분은 불투명하게 표시된다.

맵은 `config/gungang/server/maps/*.json`, 주무기는 `config/gungang/server/weapons/*.json`, 보조무기는 `config/gungang/server/sub_weapons/*.json`에 항목별로 저장합니다. 핫바 9번 기본 아이템은 `config/gungang/server/slot9.json`입니다. 맵은 새 경로만 읽으며 구형 맵 폴더를 자동 복사하지 않습니다. 기존 통합 `loadouts.json`은 원본을 보존하며 최초 한 번 새 구조로 이전합니다. 파일명 순서로 무기를 표시하고 `/gungang reload`로 변경을 적용합니다.

서버 설치 시 `config/gungang/acoustics.json`의 음향 설정을 우선 적용합니다. 맵·팀·관전자·준비 UI, 전원 준비 후 팀 스폰 이동과 30초 준비 구역 제한, E키 무기 선택과 NBT 기반 지급을 추가했습니다. 폰트 경로는 `config/gungang/fonts`입니다. 체력 감소 애니메이션은 0.12초, 피해 잔상은 0.10초 대기 후 0.35초 동안 줄어듭니다.

거점 점령·점수·승리 판정을 모드 서버에서 처리합니다. 일반 쟁탈전의 제한시간 0은 카운트업, 양수는 카운트다운이며 점수 HUD 아래에 전용 LCD 텍스처·검은 외곽선·초록 그라데이션 타이머를 표시합니다. TAB에서 K/D/A·딜량을 확인하고 종료 시 승리/전적 화면을 표시합니다. 전적은 `config/gungang/result/*.txt`에 저장하며 서버 로그에도 경기 날짜·시각과 맵 이름·ID를 남깁니다.

거점 블록은 완전히 점령해 점수를 얻는 팀의 색으로만 바뀝니다. 경기 종료 시 팀을 해제하며, 열린 로비를 다시 열 때에는 팀·준비·맵 선택을 유지합니다. 경기 중 팀 참가자는 자기 팀 스폰·리스폰 대기 중 또는 무기고 3블록 이내에서 무기를 교체할 수 있습니다. 경기 밖에서는 로비 개방 여부와 관계없이 어디서든 E키 또는 `/gungang loadout`을 사용할 수 있습니다. L키로 로비를 다시 열 수 있습니다.

**설치·명령어·맵/무기 JSON·거점 규칙:** [서버 사용 설명서](SERVER.md) · [서버 자료 기반 설정 예제](server-examples)

**모드 명령어:** [전체 명령어·권한·사용 예시](COMMANDS.md)

**아이템 NBT 복사:** 주 손에 아이템을 들고 백틱(`) 키를 누르면 `{id,Count,tag,...}` 전체 ItemStack SNBT를 클립보드에 복사합니다. 조작 설정에서 키를 바꿀 수 있으며 OP 권한은 필요 없습니다. TaCZ 총기 ID·부착물·탄약·발사 모드 등 아이템에 저장된 태그를 포함합니다. 총기 팩 파일 자체는 포함되지 않습니다. 서버의 원본 NBT를 파일로 내보내려면 `/gungang exportitem <id>`를 사용하세요.
