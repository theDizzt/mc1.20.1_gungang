## 설치와 서버·클라이언트 구분

Minecraft 1.20.1 / Java 17 / Forge 47.3.22 이상에서 같은 JAR를 서버와 클라이언트의 `mods`에 넣습니다. 제공된 `server_resource`는 Mohist 1.20.1-923, Forge 47.3.22, TaCZ 1.1.7-hotfix를 사용합니다. 빌드는 Forge 47.4.0을 기준으로 하며, Mohist의 다른 플러그인과 함께 실제 경기를 진행하는 검증은 별도로 필요합니다.

클라이언트에만 설치해도 기존 음향·HUD 기능을 사용할 수 있습니다. 서버에 설치하면 서버 음향 설정이 우선하며, 로비와 무기 UI는 클라이언트에도 이 모드가 있어야 표시됩니다. 모드 없는 클라이언트의 소리는 강제 변경할 수 없습니다. 싱글플레이에서는 개인 음향 설정을 사용합니다.

서버 최초 실행 시 `config/gungang/`에 설정과 예제를 생성합니다. 폴더별 파일 종류·등록 순서·자동 저장 데이터는 [데이터 등록 안내](DATA.md#folders)에서 확인하세요.

폰트는 각 클라이언트의 `config/gungang/fonts`에 넣습니다. 서버 폰트가 클라이언트로 자동 전송되지는 않습니다. 기존 `config/fonts`의 TTF는 최초 폴더 이전 때 새 폴더로 복사하며 기존 파일을 지우거나 같은 이름을 덮어쓰지 않습니다.

서버 `acoustics.json`에는 기존 음향 옵션과 같은 키를 사용합니다. 접속·`/gungang reload` 때 설정을 전송하고, 해당 클라이언트 옵션은 잠깁니다. HUD·폰트 설정과 Minecraft 자체 마스터 음량은 개인 설정입니다. 개인 음향 설정 파일은 덮어쓰지 않고, 서버에서 나가면 다시 개인 설정으로 동작합니다. 잘못된 범위, 알 수 없는 키, 잘못된 NBT가 있으면 재로드를 거부하고 마지막 정상 설정을 유지합니다.

## 로비와 경기 진행

팀데스매치에는 선택적으로 AI 봇을 최대 4명까지 투입할 수 있습니다. 기본 OFF이며 `/gungang bot on`으로 사용을 허용한 뒤 로비의 `플레이어 / 팀` 탭에서 `봇 추가`를 누릅니다(OP 2). 로비에서는 이름을 끌어 다른 팀 칸에 놓아 팀을 옮길 수 있습니다(관리자는 전원, 일반 플레이어는 본인만). `/gungang bot off`는 봇을 즉시 제거하고 로비 추가 버튼도 잠급니다. 성능 프리셋·무기·팀 설정은 [AI 봇 안내](BOTS.md)를 참고하세요.

로비 UI에서 관리자는 플레이어 행을 선택해 팀을 바꿀 수 있고, 일반 플레이어는 본인만 변경합니다. 새 접속자는 미배정 상태이며 관전자는 랜덤 팀 배치에서 제외합니다. 스코어보드 팀 ID는 기존 데이터팩과의 호환을 위해 `Red` / `Blue`를 유지합니다. 팀 색상은 [option.json](DATA.md#options)에서 설정합니다.

1. 관리자가 맵을 선택하고 팀을 배치합니다. 테스트를 위해 한 팀에 1명만 있어도 시작할 수 있습니다.
2. 관전자를 제외한 전원이 준비하면 즉시 선택 맵의 팀별 스폰으로 이동합니다. 미배정·준비하지 않은 플레이어가 있으면 시작하지 않습니다.
3. 일반 맵은 **30초 준비 시간** 동안 스폰 밖으로 벗어나면 돌려보냅니다. 노르망디는 **45초**이며 ALPHA는 자유 이동, BRAVO만 스폰에 대기합니다. 준비 시간에는 참가자의 피해를 막습니다.
4. 선택한 무기(기본 프리셋이 지정되어 있으면 그 프리셋, 선택이 없으면 목록의 첫 무기)를 지급하고 무기 선택 UI를 엽니다. 기본 **E**키 또는 `/gungang loadout`으로 다시 열 수 있습니다. E키는 조작 설정에서 바꿀 수 있습니다. 전투 중 스폰 밖에서는 원래 인벤토리 동작을 유지하고, 경기 밖에서는 어디서든 무기 선택창이 열립니다.
5. 준비 시간이 끝나면 이동 제한이 해제되고 맵의 제한시간이 시작됩니다. 경기 중에는 자기 팀 스폰 공간 또는 리스폰 대기 중에 무기를 바꿀 수 있습니다. 실제 좌표·팀·아이템 ID는 서버가 매 요청마다 검증합니다.
6. 제한시간 또는 `/gungang stop`으로 종료하면 참여 전 위치와 게임 모드로 돌아가며 인벤토리 전체를 초기화하고 slot9 아이템만 재지급합니다. 시작 전 아이템을 복원하지 않습니다. 팀과 준비 상태는 해제됩니다.

치명타를 받으면 모드가 사망을 기록하고 관전 대기로 전환합니다. 기본 5초 뒤 팀 스폰에서 체력·허기를 회복하고 선택한 무기를 다시 지급합니다. 이 시간에는 E 또는 `/gungang loadout`으로 무기를 바꿀 수 있습니다. 처치자가 살아 있고 접속해 있으면 3인칭으로 관전합니다. 자살(데스존, 낙사·익사·공허 같은 환경사, 자기 폭발물 등 처치자가 없거나 자신인 사망)이면 부활 대기 시간 동안 죽은 자리에서 시점만 자유롭게 돌리며 관전합니다. 공허 사망은 월드 최저 높이 2블록 위에서 관전합니다. 처치자를 관전하다 처치자가 죽거나 나가면 팀 스폰에서 대기합니다. 종료 시 원래 시점으로 복원합니다. 경기 사망은 모드가 처리하므로 바닐라 사망 화면·사망 횟수를 트리거로 하는 데이터팩 부활 효과를 실행하지 않습니다.

자신과 팀원의 초상화에는 포션 색상 대신 서버가 보내는 실제 부활 대기 시간과 점진적으로 밝아지는 효과를 표시합니다. 경기 중 접속자는 관전자로 들어오며 `/gungang join`으로 참가할 수 있습니다. 이미 참가한 플레이어는 이 명령으로 팀을 바꾸거나 리스폰을 건너뛸 수 없습니다. 접속 종료 시 로비 참여 상태를 정리하며 서버 강제 종료 이후 경기 복구는 제공하지 않습니다.

## 로비·무기·맵 화면

### 무기 화면

무기 목록은 분류와 이름을 구분하고 장착한 무기에 초록 `●`을 표시합니다. 목록은 기본으로 카테고리별로 묶어 정렬하며, 카테고리 순서는 서버 무기 파일에서 처음 나오는 순서를, 같은 카테고리 안에서는 파일 순서를 따릅니다. 상세 패널에는 분류·`장착 중` 배지를 표시하고, 장착 버튼은 `선택한 무기 장착` 또는 `장착 중인 무기`로 구분합니다. 3D 미리보기에는 그라데이션·격자·모서리 강조선을, 능력치 막대에는 테두리·그라데이션·끝 표시선을 적용합니다. 설명에는 `사용방법` 소제목과 막대 기준 안내, 무기 JSON에 `releaseDate`가 있으면 `출시 yyyy.MM.dd`를 표시하며 스크롤 영역에는 위아래 페이드와 트랙을 표시합니다.

상세 카드는 위에서부터 무기 이름, 미리보기(왼쪽)와 능력치(오른쪽), 설명·사용방법(전체 폭) 순서로 배치합니다. 카테고리는 미리보기 왼쪽 아래에 표시합니다. 서버에 등록한 아이템의 실제 NBT 모델을 표시하며, 미리보기 영역에서 왼쪽 드래그로 회전하고 휠로 확대/축소합니다. 체력·이동 속도와 숫자형 스펙은 한 줄에 이름·막대·값으로 표시하며, 막대는 목록 내 같은 단위의 최댓값에 대한 상대값입니다. 텍스트 스펙은 원문을 유지합니다. 설명 영역과 무기 목록은 각각 스크롤할 수 있습니다. 명령어 전용 보조무기는 미리보기용 아이템 NBT가 없으므로 모델 없음으로 표시합니다. 미리보기 때문에 지급 명령어를 실행하지 않습니다.

### 프리셋

무기 화면의 세 번째 탭 `프리셋`에서 주무기·보조무기 조합을 플레이어당 최대 5개 저장합니다. 왼쪽 목록에 슬롯 1~5와 이름을 표시하고, 경기 시작 기본값으로 지정한 슬롯에는 `★`를 붙입니다.

| 버튼 | 동작 |
| --- | --- |
| 현재 장비 저장 / 현재 장비로 덮어쓰기 | 지금 장착한 주무기·보조무기 ID를 선택한 슬롯에 저장합니다. 아직 고르지 않은 칸은 목록의 첫 무기로 저장합니다. |
| 장착 | 프리셋의 두 무기를 장착합니다. 일반 장착과 같은 조건(로비, 리스폰 대기, 자기 팀 스폰, 무기고 근처)에서만 동작합니다. 보조무기를 바꿀 수 없는 폭탄·해체기 담당자는 주무기만 바뀝니다. |
| 기본값 설정 / 해제 | 경기 시작과 경기 중 참가(`/gungang join`) 때 이 프리셋을 자동 장착합니다. 지정하면 로비에서 고른 무기보다 우선합니다. |
| 이름 변경 | 20자 이하. 입력 칸에서 Enter로도 저장합니다. 비우면 `프리셋 N`이 됩니다. |
| 삭제 | 두 번 눌러 확인합니다. 기본값 프리셋을 지우면 기본값도 해제됩니다. |

프리셋은 서버의 `player-db.json`에 저장되므로 클라이언트를 바꿔도 유지됩니다. 서버 설정에서 사라진 무기 ID가 들어 있으면 경기 시작 시 해당 칸만 목록의 첫 무기로 대신 지급하고, 수동 장착은 `등록되지 않은 무기입니다`로 거부합니다. 저장 형식은 [누적 전적 DB](GAMEPLAY.md#progression)를 참고하세요.

### 맵 화면

미리보기 카드에 모드와 `현재 선택` 배지를 표시합니다. 맵 설명 줄 오른쪽에는 맵 JSON의 `releaseDate`를 `출시 yyyy.MM.dd`로 표시합니다([맵 JSON](DATA.md#maps)). 이미지는 테두리 안에 표시하며 미리볼 맵이 없으면 안내 문구를 표시합니다. 맵이 한 화면보다 많으면 목록 위에서 휠로 한 줄씩 스크롤하거나 오른쪽 스크롤바를 드래그하며, `‹`·`›` 버튼은 한 화면씩 이동합니다.

1. PNG 이미지를 서버의 `config/gungang/server/maps/preview/`에 넣습니다.
2. 해당 맵 JSON의 최상위에 `"previewImage": "iljang.png"`를 지정합니다.
3. 로비에서 `/gungang reload` 후 맵 선택 화면을 다시 엽니다.

이미지는 최대 1 MB(1,000,000바이트), 가로·세로 각각 2048픽셀까지 지원합니다. 하위 경로 없이 파일명만 지정합니다. 빈 문자열이면 미리보기를 생략합니다. 선택한 이미지가 클라이언트로 전송되므로 클라이언트에 별도로 복사할 필요는 없습니다. 원본 비율을 유지하며 관리자만 실제 경기 맵을 변경할 수 있고, 다른 플레이어도 목록을 눌러 미리볼 수 있습니다.

### 로비와 공통 화면 스타일

로비는 ALPHA·BRAVO·미배정/관전자 카드를 구분하고 팀 색 띠, 인원·준비 인원을 표시합니다. READY는 초록, 대기는 주황, 미배정·관전자는 회색이며 자신의 행에는 `(나)`가 붙습니다. 선택한 대상은 팀 색으로 강조하고 빈 팀에는 안내를 표시합니다. 미배정/관전자 목록이 여러 페이지면 카드 머리에 페이지를 표시합니다. 상단에는 맵·모드를 구분해 표시하며 활성 맵이 없으면 경고색을 사용합니다. `준비 완료`는 강조색 채움, `준비 취소`는 주황 테두리로 구분합니다.

로비·무기 선택·경기 결과 화면은 공통 그라데이션 배경, 패널 테두리·그림자, 헤더 띠·구분선과 제목 강조 막대를 사용합니다. 버튼은 호버·선택·주요 동작·비활성 상태를 구분하며 일반 버튼은 가운데, 목록 항목은 왼쪽 정렬입니다. 2026-10-13 변경은 표시 개선으로, 기존 버튼 위치와 클릭·드래그·휠 조작 및 서버 요청 동작은 유지합니다.

모델 원본과 리소스 재생성 방법: [전쟁 탁자](../models/war_table/README_KO.md) · [전쟁 탁자 Forge 적용](../models/war_table/FORGE_MODEL_NOTES.md) · [무기고](../models/armory/README_KO.md) · [무기고 Forge 적용](../models/armory/FORGE_MODEL_NOTES.md).

## 음향·HUD·폰트·키 설정

### 팀 HUD와 킬로그

HUD는 **1단위 = 프레임버퍼 2픽셀**로 고정됩니다. 같은 해상도에서 GUI 배율을 변경해도 크기와 왼쪽/아래 여백이 유지됩니다.
창 해상도를 변경하면 해당 화면의 왼쪽/아래에 다시 맞추며, 매우 작은 화면에서는 공간에 맞게 목록을 제한합니다.

- 바닐라 스코어보드의 같은 팀을 사용합니다. 본인 초상화 테두리는 팀 색상, 팀이 없거나 색상이 지정되지 않으면 흰색입니다.
- 왼쪽 상단 팀원 목록은 온라인 팀원의 초상화, 체력 숫자·막대, 현재 주손 무기를 표시합니다. 너비는 본인 HUD와 같은 140단위(280픽셀)이며 전체 패널 배경은 없습니다. 아이템 슬롯과 체력바 배경은 불투명합니다. 이름순이며 넘치는 인원은 `+숫자`로 표시합니다.
- 먼 거리·다른 차원 등 서버 추적 범위 밖의 팀원은 이름과 초상화만 표시하며, 체력은 `--`, 무기는 빈칸입니다. 값을 추정하지 않습니다.
- 같은 팀원의 스킨 모델을 검은색으로 먼저 투시 렌더링한 뒤 일반 모델을 그립니다. 벽에 가려진 부분은 검은 실루엣, 보이는 부분은 일반 스킨입니다. 서버가 전송하고 클라이언트가 렌더링하는 플레이어만 대상이며, 투명 효과나 별도 모델 렌더러·셰이더팩은 추가 호환 검증이 필요합니다.
- 기존 우측 상단 `0:00` 표시자는 없앴습니다. 경기 타이머는 모드별 점수 HUD와 함께 표시하고, 액션바는 바닐라 위치에 표시합니다.
- 오른쪽 상단 킬로그는 `[공격자 얼굴·이름] KILLED [피해자 얼굴·이름] ☠` 또는 `DIED [피해자 얼굴·이름] ☠` 형식으로 오른쪽 정렬합니다. 최근 최대 5개를 각각 8초 표시합니다. 새 줄은 오른쪽에서 미끄러져 들어오고, 끝날 때는 오른쪽으로 밀려나며 사라집니다. 커스텀 HUD와 킬로그가 켜져 있으면 인식된 사망 메시지는 채팅에서 숨겨 우측 상단에만 표시하며, HUD 또는 킬로그를 끄면 채팅 메시지는 유지합니다. 서버의 표준 번역형 사망 메시지를 사용하므로 `showDeathMessages=false` 또는 일반 문자열로 대체된 메시지는 감지하지 않습니다. 스킨 정보를 찾을 수 없으면 기본 얼굴을 표시합니다.
- **설정 → 팀·킬로그**에서 목록·킬로그·실루엣을 각각 전환합니다. 목록과 킬로그는 커스텀 HUD가 켜져 있을 때 표시됩니다. 실루엣은 독립 옵션이며 F1에서는 숨깁니다.
- 서버 설치는 필요 없습니다. 내부 ID와 설정 파일명 `gungang_acoustics`는 기존 설정 호환을 위해 유지합니다.

Minecraft **1.20.1 / Forge 47.3.22 이상(47.x) / Java 17**용 음향·HUD 모드이며 서버 로비 기능을 선택적으로 사용할 수 있습니다.
일반 위치 기반 소리와 TaCZ 총기 소리에 거리 감쇠·벽 차음·고음 감소를 적용합니다.
서버 설치는 필요하지 않습니다. TaCZ를 필수 의존성으로 요구하거나 JAR에 포함하지 않습니다.

### 구현 범위

- 일반 발소리·위치 기반 효과음: 근거리 음량을 유지한 뒤 음압 기준 약 `1/r` 감쇠. 기존 소리의 최대 가청 거리 마지막 25% 구간에서 부드럽게 무음으로 전환합니다.
- 벽: 레이가 실제 블록 충돌 형상을 통과한 길이에 재질별 손실(dB/블록)을 곱합니다. 겹치는 형상 구간은 합쳐서 중복 계산하지 않습니다.
- FPS 가시성: 위치가 근처 플레이어와 대응하는 발소리·TaCZ 소리는 머리·어깨·몸통·다리의 16개 지점을 검사합니다. 하나라도 열린 경로가 있으면 차폐와 고음 감소를 즉시 해제합니다. 완전히 가려지면 가장 덜 막힌 신체 경로를 사용합니다.
- F5 시점: 청취 위치는 1·3인칭 모두 플레이어 눈높이로 고정합니다. 기본 F5 카메라에서도 상대의 신체 지점이 보이면 차폐를 해제하므로 언덕 뒤에서 상체만 보이는 상황을 처리합니다. 거리 감쇠는 유지합니다.
- 최소 음량: 차폐 음량 하한은 기본 **16%**이며 설정에서 0~100%로 변경합니다. 거리·소음기·마스터/카테고리 볼륨·음소거를 적용한 원래 음량에 대한 차폐 배율입니다. 멀리 있는 소리를 무조건 크게 만드는 옵션은 아닙니다.
- 두꺼운 벽·여러 벽: dB 손실을 누적합니다. 얇은 유리판·반블록·열린 문은 충돌 형상에 따라 달라집니다.
- 벽 뒤 고음: OpenAL EFX low-pass 필터를 사용합니다. EFX가 없는 장치에서는 차음 음량만 적용하며 경고를 한 번 기록합니다.
- 회절 근사: 첫 장애물 주변에서 양쪽 구간이 모두 열린 1회 꺾임 경로를 탐색하고, 우회 길이에 따라 작고 먹먹한 소리를 합성 음량에 반영합니다.
- 재생 중 이동·문 개폐: 활성 사운드를 순환 갱신하고 차음 변화를 시간 기반으로 완화합니다.
- 소리 재생·정지·루프·카테고리/마스터 볼륨 제어는 기존 엔진에 맡깁니다. 음악·음반·UI/상대 좌표 소리는 제외합니다.

### 발소리·무기 음량

**설정 → 음량**에서 발소리와 무기 소리를 각각 0~300%로 조절합니다. 기본 100%, 50%는 절반, 200%는 두 배, 0%는 음소거입니다. `footstepVolume`, `weaponVolume`으로 TOML에서도 설정할 수 있습니다. 음향 효과를 꺼도 적용되며 거리 감쇠·차폐·마스터/카테고리 음량을 유지합니다. 제외 목록의 소리는 변경하지 않습니다. 설정 저장 후 재생 중인 소리에도 순차 반영됩니다.
발소리는 step/footstep 이벤트, 무기는 TaCZ GunSoundInstance 계열과 발사·재장전·활·석궁·삼지창·공격 이벤트 이름을 인식합니다. 독자적인 이름이나 오디오 엔진을 쓰는 모드는 자동 분류되지 않을 수 있습니다.

### TaCZ 및 애드온

TaCZ의 `GunSoundInstance`와 그 하위 클래스(엔티티 추적 소리 및 같은 클래스를 쓰는 애드온)를 선택적으로 인식합니다.
TaCZ는 `Attenuation.NONE`을 쓰면서 생성 시 자체 거리 감쇠를 음량에 반영하므로, **TaCZ에는 거리 감쇠를 추가로 곱하지 않습니다**.
TaCZ가 정한 거리·소음기·건팩 음량을 유지하면서 벽 투과·우회 근사·고음 감소만 적용합니다.
따라서 아래 `referenceDistance`/`rolloff`는 일반 소리에 적용되며 TaCZ 자체 감쇠 곡선을 교체하지 않습니다.
TaCZ의 긴 소리가 생성 이후 이동에 따라 음량을 재계산하지 않는 경우, 이 모드도 그 거리 동작을 유지합니다.

다른 네임스페이스의 건팩도 위 클래스를 이용하면 처리됩니다. 독자적인 오디오 엔진을 사용하는 애드온은 별도 지원이 필요합니다.
확인한 실제 배포본은 `tacz-1.20.1-1.1.8-hotfix2.jar`이며, 사용자의 정확한 버전·애드온 목록은 아직 확인하지 못했습니다.
Sound Physics Remastered 등 동일 OpenAL 필터를 제어하는 모드와의 병용은 검증하지 않았습니다. 직접 필터를 서로 덮어쓸 수 있습니다.

### 총게임용 HUD

서바이벌 이외의 모드에서는 중앙 체력바 오른쪽에 게임 모드명을 표시합니다. 관전자 모드에서도 커스텀 HUD를 표시하되 바닐라 관전자 조작은 유지합니다.
플레이어 반경 96블록 안에서 클라이언트에 로드된 모든 살아 있는 엔티티의 머리 위에 체력 막대를 표시합니다. 본인·같은 팀 플레이어·관전자·보이지 않는 대상은 제외합니다. 막대는 머리 가까이 낮추어 기본 이름표 아래에 배치하며, 깊이 판정으로 블록 뒤에 가려집니다.

본인 체력바는 화면 하단 중앙에 배치하며, 이전 72×14 HUD 단위에서 약 230×22단위로 확대했습니다(가로 3.2배·세로 1.6배를 정수 반올림). 숫자는 막대 안 왼쪽에 표시하며 체력 변화 애니메이션을 유지합니다. 닉네임은 초상화 옆 기존 체력바 자리로 이동했습니다. 좁은 창에서는 초상화·슬롯과 겹치지 않도록 중앙 체력바를 위로 올립니다.

기본값으로 총게임용 HUD가 켜집니다. 바닐라 9칸 핫바·하트·경험치·배고픔 바를 숨기고 화면 왼쪽 아래에 다음 정보를 표시합니다.
큰 스킨 초상화 옆에는 플레이어 이름과 두 아이템 슬롯을 표시하며, 확대된 체력바는 화면 하단 중앙에 표시합니다.

- **핫바 1번 슬롯**: 현재 선택한 슬롯과 관계없이 인벤토리 첫 번째 핫바 아이템. 1번을 선택하면 테두리가 강조됩니다.
- **왼손 아이템**: 보조 손 슬롯. 빈 슬롯은 빈 프레임으로 표시하고 아이템 수량·내구도 표시도 유지합니다.
- **플레이어 초상화**: 본인 스킨의 얼굴 및 모자 레이어.
- **체력**: `20`처럼 현재 체력만 정수로 표시합니다. 소수는 올림하므로 살아 있는 0.1 체력은 `1`로 보입니다. 막대는 실제 현재/최대 체력 비율을 반영하며 낮은 체력은 노랑/빨강으로 구분합니다. 흡수 체력은 일반 체력 뒤의 노란 구간으로 표시합니다.
- **체력바 애니메이션**: 본인·팀원 막대는 피해 시 0.12초, 회복 시 0.35초에 걸쳐 부드럽게 이동합니다. 피해 잔상은 0.10초 대기 후 0.35초 동안 줄어듭니다. 연속 피격·회복은 현재 표시 위치에서 이어집니다. 숫자와 본인 막대의 위험 색상은 실제 체력을 즉시 반영합니다. 처음 표시할 때, 최대 체력이 바뀔 때, 1초 이상 표시하지 않았다가 다시 표시할 때는 현재 비율로 맞춥니다.
- **배경**: 본인 아이템 슬롯과 체력바의 빈 영역·테두리·채워진 체력 부분은 모두 불투명합니다.

**모드 → GunGangRealistic → 설정 → HUD → 총게임용 HUD: 꺼짐 → 저장 후 닫기**로 기본 핫바와 하트를 복원합니다.
설정 파일에서는 `shooterHud = false`로 바꿀 수 있습니다. 음향 효과의 전체 활성화 옵션과는 독립적입니다.
슬롯 선택·아이템 사용 조작은 그대로이며 HUD는 표시만 변경합니다. 관전자 모드의 기본 조작은 유지하고 F1에서는 커스텀 HUD를 숨깁니다.
커스텀 HUD에서는 바닐라 갑옷·산소 게이지를 숨기고 물속 호흡 잔량을 체력바 안에 표시합니다. TaCZ 자체 표시는 유지합니다. HUD 탭의 가로/세로 오프셋으로 왼쪽/아래 테두리에서의 거리를 고정 단위(2픽셀) 단위로 지정합니다.
가로 값을 높이면 오른쪽, 세로 값을 높이면 위쪽으로 이동하며 화면 밖으로 나가지 않게 제한합니다. HUD를 끄면 숨긴 바닐라 표시를 모두 복원합니다.

보스바는 바닐라의 상단 중앙 위치·제목·가로 길이를 유지합니다. 막대 높이는 작은 퍼센트 글씨가 들어가도록 9 GUI 단위이며, 서버가 지정한 색상과 분할 표시를 따릅니다. 채워지는 양은 부드럽게 전환되고 사선 무늬가 흘러 충전 느낌을 냅니다. 막대 중앙에는 표시된 채움 비율을 `99.9%` 형식의 작은 흰 글씨와 검은 외곽선으로 표시합니다.
실제 체력 감소 또는 피격 중 흡수 체력 감소를 감지하면 화면 가장자리에 약 1.1초 동안 피해 비네트를 표시합니다. 체력이 높을 때는 검은색에 가깝고 낮을수록 붉어지며, 중앙 조준 영역은 비워 둡니다.
포션 효과가 있으면 본인·팀원 초상화에 효과 색상을 반투명하게 입힙니다. 여러 효과는 강도에 따라 혼합하고, 다른 플레이어의 상세 효과가 없으면 서버가 동기화한 효과 색상을 사용합니다.
채팅 메시지와 입력창은 본인 HUD 위로 이동하며 검은 배경은 제거합니다. 링크·호버·메시지 대기열 클릭 좌표도 이동 위치에 맞춥니다. 이 UI 변경들은 총게임용 HUD를 끄면 기본 표시로 돌아갑니다.

### 게임 전체 폰트

**설정 → 글자 위치**에서 폰트 가로·세로 오프셋을 -8~8 범위의 소수로 조절합니다. 기본값은 가로 0, 세로 +1이며 양수는 오른쪽·아래 방향입니다. 글자가 위로 떠 보이면 세로 값을 높이세요. HUD·채팅·메뉴·월드의 커스텀 TTF에 적용되며 저장 시 리소스를 다시 불러옵니다. HUD 글자 크기·굵기 옵션도 이 탭에 있습니다.

킬로그의 이름과 초상화 테두리는 해당 플레이어의 스코어보드 팀 색상을 사용하며, 팀 색상이 없으면 흰색으로 표시합니다.

커스텀 TTF가 켜져 있으면 Bold 서식도 일반 굵기로 표시합니다. HUD·채팅·메뉴·월드 텍스트의 합성 볼드를 제거하고 너비 계산도 일반 굵기에 맞춥니다.

기본 폰트는 **Galmuri11-Bold.ttf**이며 누락 글자는 바닐라 폰트로 보완합니다. 외부 TTF를 선택하면 외부 폰트 → Galmuri11 Bold → 바닐라 순서로 적용합니다.

**모드 → GunGangRealistic → 설정 → 폰트 → 커스텀 TTF 폰트**에서 전환합니다. 기본값은 켜짐입니다.

**게임의 `config/gungang/fonts` 폴더에 `.ttf` 폰트 파일을 넣으면 사용할 수 있습니다.** 폴더는 모드 실행 시 자동으로 생성됩니다. 일반 설치는 `.minecraft/config/gungang/fonts`, 개발 실행은 `run/config/gungang/fonts`입니다.

1. 원하는 TTF를 `config/gungang/fonts`에 넣습니다(예: `config/gungang/fonts/MyFont.ttf`).
2. 게임을 실행하거나, 실행 중이라면 **F3+T**로 리소스를 다시 불러옵니다.
3. 파일이 하나면 자동 적용됩니다. 여러 개면 파일명 순으로 첫 TTF를 사용합니다. 원하는 파일을 지정하려면 폰트 탭의 **TTF 파일명**에 `MyFont.ttf`처럼 확장자를 포함한 파일명만 입력하고 저장합니다. 한글·공백이 있는 파일명도 사용할 수 있습니다.

TTF 파일명을 비우면 자동 선택으로 돌아갑니다. 폴더가 비어 있거나 지정한 파일이 없거나 읽을 수 없는 TTF이면 JAR에 포함된 `font/Galmuri11-Bold.ttf`를 사용합니다. 읽기 실패는 로그에 기록합니다. 외부 폰트에 없는 글자는 내장 Galmuri11 Bold와 바닐라 폰트가 보완합니다. 같은 파일명으로 폰트를 교체한 경우에도 **F3+T**로 갱신하세요.
같은 탭의 **HUD 글자 크기(100~150%, 기본 150%)**, **HUD 글자 굵게(기본 켜짐)**로 본인·팀원 이름과 체력 표시를 조절합니다. 이름은 확대 후 너비로 잘라 슬롯 밖으로 넘치지 않게 하며, 이중으로 보이는 그림자는 제거했습니다. 기본 150%는 화면 3픽셀 배율로 그립니다.
켜면 선택형 내장 리소스팩을 통해 메뉴·채팅·HUD의 기본 폰트에 적용하고, 끄면 게임/다른 리소스팩 폰트로 복원합니다. 저장하면 리소스를 다시 불러오므로 재시작할 필요가 없습니다.
논리 글자 크기는 9로 유지하며, **TTF 해상도 배율**에서 글리프 생성 해상도를 정수 **1~8배(기본 6배)**로 조절합니다. 이 값은 선택한 외부 TTF와 내장 Galmuri11 Bold 폰트에 적용되며 화면의 글자 크기를 바꾸지 않습니다. 배율이 커지면 글리프 메모리는 대략 배율의 제곱에 비례해 늘고, 처음 표시할 글자를 생성하는 비용도 증가합니다. 메모리가 부담되면 3배로 낮출 수 있습니다.

**폰트 부드럽게 표시(기본 켜짐)**는 1배보다 높은 해상도의 단색 글꼴 아틀라스에 선형 필터링을 적용합니다. 리소스팩의 TTF에도 적용되며 컬러 비트맵 글꼴은 제외됩니다. 끄면 최근접 필터로 픽셀 경계가 뚜렷해집니다. 커스텀 폰트, 해상도 배율 또는 부드럽게 표시를 변경하고 저장하면 리소스를 자동으로 다시 불러옵니다. TOML을 직접 수정할 때는 게임을 종료한 상태에서 수정한 뒤 다시 실행하세요.

커스텀 TTF에서는 HUD 합성 볼드와 그림자 없이 원래 획을 표시합니다. HUD 굵게 옵션은 기본 폰트에만 적용됩니다. 없는 글자는 바닐라 공급자로 대체하며 유니코드 폰트를 덮어쓰지 않아 '유니코드 글꼴 강제 사용'으로도 복원할 수 있습니다.
고해상도 렌더링은 [ModernUI-MC](https://github.com/BloCamLimb/ModernUI-MC)의 접근을 참고했습니다. ModernUI 설치는 필요 없으며, 이 구현은 기존 Minecraft TTF 공급자와 선형 필터링을 사용합니다. ModernUI의 SDF·FreeType 힌팅·화면 배율별 동적 래스터화는 포함하지 않습니다. 구현 메모는 [폰트 렌더링 문서](DEVELOPMENT.md#font-rendering)에 있습니다.
글꼴마다 모양·글리프 범위가 다르므로 모든 언어·해상도에서 깨짐이 없다고 보장하지 않습니다. 전용 폰트를 사용하는 모드 표시는 별도입니다.

### 왼손 아이템 매크로

**설정 → 조작 → 키 설정 → GunGangRealistic · 왼손 아이템**에서 키를 변경할 수 있습니다.
모드 설정의 **HUD 탭 → 왼손 매크로 키 설정 열기** 버튼으로도 해당 마인크래프트 키 설정 화면에 들어갑니다.
키 배정은 Minecraft의 `options.txt`에 저장됩니다. 다른 모드와 G/H가 겹치면 이 화면에서 충돌을 해소하세요.

| 기본 키 | 동작 |
|---|---|
| **G** | 왼손 아이템을 주손으로 교환 → 한 번 좌클릭/공격 → 원래 주손과 슬롯으로 복귀 |
| **H** | 왼손 아이템을 주손으로 교환 → 우클릭/사용 → 원래 주손과 슬롯으로 복귀 |

음식·활·방패 등 지속 사용 아이템은 **H를 누르고 유지**합니다. 사용 완료 또는 H를 놓으면 사용을 종료하고 복귀합니다.
G는 연속 채굴이나 자동 연타가 아닌 한 번의 공격입니다. 조준 대상·사거리·아이템 쿨다운은 원래 게임 규칙을 따릅니다.
손 교환 후 기본 갱신을 기다리고 입력하므로 짧은 지연이 있습니다. 이미 실행 중인 매크로에 대한 추가 입력은 버립니다.

TaCZ 총기는 선택적 API 연동으로 G에 발사 요청 한 번, H에 누르는 동안 조준을 적용합니다.
총 꺼내기/쿨다운/차지 준비는 최대 약 5초 기다리며, 탄약 부족·장전 필요·이벤트 취소는 강제로 무시하지 않고 복귀합니다.
TaCZ 일반 입력이 매크로의 차지를 매 틱 취소하거나 중복 발사하지 않도록 해당 기간의 발사/조준 폴링을 제어합니다.
같은 TaCZ API를 사용하는 건팩이 대상이며, 독자 입력을 사용하는 다른 무기 모드는 별도 확인이 필요합니다.

메뉴·채팅 중, 관전자, 사망, 왼손이 비어 있을 때, 기존 아이템 사용/공격 중에는 시작하지 않습니다.
매크로 중 메뉴 열기·포커스 상실·슬롯 변경은 사용을 중단하고 원래 슬롯으로 복귀합니다. 지속 사용의 안전 제한은 약 60초입니다.
서버에는 실제 손 교환·사용 패킷을 순서대로 전송하며, 클라이언트도 손 교환을 예측합니다.
복귀할 때 저장해 둔 아이템 복사본을 덮어쓰지 않고 **현재 남아 있는 스택을 교환**하므로 소모 수량·내구도 변화가 유지됩니다.
서버가 손 교환/사용을 거부하거나 별도 인벤토리 제약을 적용하는 환경의 동작은 실서버에서 확인해야 합니다.

### 설치

1. `dist/gungang-realistic_1.20.1_u<업데이트번호>_<yyMMdd>.jar`를 플레이할 클라이언트의 `mods` 폴더에 넣습니다.
2. 첫 실행 후 생성되는 `config/gungang_acoustics-client.toml`에서 설정합니다.
3. 벽 차음 비교는 동일한 총·거리·음량으로 진행합니다.

게임의 **모드(Mods) → GunGangRealistic → 설정(Config)** 에서 옵션 화면을 열 수 있습니다. 별도 설정 UI 모드는 필요 없습니다.
한국어/영어를 지원하며 게임 언어 설정을 따릅니다.

- **음향 효과**: 전체 효과, 벽 뒤 고음 감소, 모서리 우회 효과, 벽 차음 강도, 변화 완화 시간, 최소 음량(%).
- **거리·성능**: 근거리 유지 거리, 감쇠 강도, 틱당 갱신 수, 벽 계산 거리, 우회 탐색 범위.
- **예외·재질**: 효과를 제외할 사운드 ID와 블록별 차음 값. 여러 항목은 쉼표로 구분합니다.
- **HUD**: 총게임용 표시와 바닐라 표시 전환, 가로/세로 오프셋, 키 설정 바로가기.
- **팀·킬로그**: 팀원 목록, 킬로그, 팀원 검은 실루엣.
- **폰트**: 커스텀 TTF 전환, TTF 파일명, 해상도 배율, 부드럽게 표시, HUD 글자 크기·굵기.

입력창에 마우스를 올리면 범위와 설명이 나옵니다. **저장 후 닫기**를 누르면 TOML 파일에 저장하고 활성 소리에 순차 적용합니다.
일시정지 중에는 게임을 재개한 뒤 반영됩니다. **취소/Esc**는 저장하지 않으며, **기본값**은 모든 탭의 입력만 초기화합니다(저장해야 적용).
잘못된 입력은 빨간색으로 표시하고 저장을 막습니다. TaCZ의 자체 거리·소음기 설정은 이 화면에서도 변경하지 않습니다.

| 설정 | 기본값 | 의미 |
|---|---:|---|
| `enabled` | `true` | 효과 활성화 |
| `shooterHud` | `true` | 총게임용 HUD 사용. 끄면 바닐라 핫바·하트 복원 |
| `hudOffsetX` / `hudOffsetY` | 각각 `8` | 왼쪽 / 아래 테두리에서의 HUD 거리(고정 단위(2픽셀)) |
| `teamHud` / `killLog` / `teamSilhouettes` | 각각 `true` | 팀원 목록 / 킬로그 / 팀원 검은 실루엣 |
| `customFont` | `true` | 외부 TTF 또는 내장 Galmuri11 Bold 폰트 사용 |
| `fontFile` | `""` | `config/gungang/fonts`의 TTF 파일명. 빈 값은 파일명 순 자동 선택 |
| `fontOversample` | `6` | 선택한 외부 TTF와 내장 TTF 생성 해상도, 정수 1~8배. 화면 글자 크기는 유지 |
| `fontSmoothing` | `true` | 오버샘플링된 단색 글꼴의 선형 필터링 |
| `hudTextSize` | `150` | HUD 이름·체력 글자 크기, 100~150% |
| `hudBoldText` | `true` | 기본 폰트의 HUD 글자를 굵게 표시. 커스텀 TTF에는 미적용 |
| `minimumEffectVolume` | `16` | 차폐 배율의 최소 음량(%) |
| `lowPass` | `true` | 벽 뒤 고음 감소 활성화 |
| `referenceDistance` | `2.0` | 일반 소리의 근거리 유지 구간(블록) |
| `rolloff` | `1.0` | 일반 소리 거리 감쇠 강도 |
| `wallStrength` | `1.0` | 재질 차음 손실 배율 |
| `smoothingSeconds` | `0.10` | 차음 변화 완화 시간 |
| `updatesPerTick` | `12` | 틱당 활성 소리 갱신 수 및 신규 소리의 회절 탐색 예산 |
| `maxTraceDistance` | `96` | 이 거리 이내만 벽/우회 계산. 초과 시 벽 효과를 생략 |
| `diffraction` | `true` | 우회 경로 탐색 |
| `diffractionRadius` | `4` | 주변 탐색 범위. 1·2·4·8블록 단계 중 설정값 이하 사용 |
| `excludedSounds` | `[]` | 제외할 `namespace:sound` 또는 `namespace:*` |
| `materialOverrides` | 유리 7 dB/블록 | `"minecraft:stone=18"` 형식의 재질 덮어쓰기 |

기본 재질 계수는 **FPS 가독성을 위한 조정 가능한 근삿값**입니다. 기본 석재 6, 나무·모래류 4, 양털 8, 금속 9 dB/블록으로 완화했습니다.
기본 유리 계수는 3이며, 기존 기본 재질 목록의 바닐라 유리/유리판 명시값 7은 호환을 위해 유지합니다. 사용자 재질 덮어쓰기는 그대로 우선합니다.
기본 석재 1/2/3블록 통과 시 차폐 배율은 약 58%/37%/27%로 줄고, 여러 벽에서도 16% 하한에 점진적으로 접근합니다.
충돌 형상이 없는 식물 등은 레이를 막지 않습니다. 월드를 읽는 작업은 클라이언트 스레드, OpenAL 작업은 사운드 스레드에서 수행합니다.
동시 발사가 많으면 신규 소리의 비싼 우회 탐색을 줄이되 직선 경로의 벽 차음은 계산합니다.

### 체력바 및 수중 음향 업데이트
- 메인 체력바에는 흐르는 사선 무늬를 표시하며, 메인·팀원·머리 위 체력바 모두 피해 잔상이 잠시 남았다가 줄어듭니다. 팀원 체력바는 흰색입니다.
- 체력 숫자는 기존 HUD 글자보다 20% 크게 표시하되 막대 높이에 맞춰 제한하고 세로 중앙에 배치합니다.
- 바닐라 상단 포션 아이콘은 커스텀 HUD가 켜져 있을 때 메인 체력바 안쪽 오른편에 작은 아이콘으로 표시합니다. 공간이 부족하면 일부 아이콘은 생략됩니다.
- 음량 설정의 `footstepOcclusion`(기본 켜짐)을 끄면 발소리의 벽 차폐를 해제합니다. 거리·사용자 음량·수중 효과는 유지됩니다.
- `waterEffects`(기본 켜짐)는 음원–청취자 사이의 물속 거리, 수면 경계 통과, 청취자의 잠수 상태를 반영합니다. 공기–물의 임피던스 차이에 따른 경계 손실을 게임용으로 완화하고 물속에서 고음을 줄이는 근사입니다. 파동 시뮬레이션이나 실제 수중 청감의 정밀 재현은 아닙니다. 경로당 최대 96회 샘플링하며 제외된 소리·음악에는 적용하지 않습니다. `lowPass`를 끄면 수중 고음 감소도 꺼집니다.


### 나침반 및 총소리 방향
- 내 체력바 위에 작은 나침반을 표시합니다. N/NE/E/SE/S/SW/W/NW 8방위, 1도 간격 눈금, 현재 방향 `000°`–`359°`를 표시합니다. 북쪽(-Z)이 0°, 동쪽(+X)이 90°입니다.
- 다른 플레이어 시점을 관전하는 중이면 모든 모드에서 나침반 위에 `관전 중: <이름>`을 표시합니다. 숨바꼭질의 변신 블록 안내는 그 위에 표시합니다.
- HUD 설정의 **나침반 / 적팀 총소리 방향**(`compass`, 기본 켜짐)으로 켜고 끕니다.
- 재생된 총소리를 감지하면 발사 당시 위치를 기준으로 적팀 방향에 표식을 약 2.5초 표시합니다. 나침반 범위 밖의 소리는 좌우 화살표로 표시하며, 이동·회전에 따라 방향이 갱신됩니다.
- TaCZ 1.1.8의 총소리에서 발사자와 실제 사운드 ID를 가져옵니다. 다른 모드는 발사 계열 사운드 ID와 음원 근처 플레이어를 대응시킵니다. 본인·같은 팀·팀 정보가 없는 대상·음소거된 소리·재장전·빈 탄창 소리는 제외합니다. 상대 팀은 서버 스코어보드 팀 기준이며, 별도 팀 시스템이나 비표준 사운드 이름을 쓰는 애드온은 감지되지 않을 수 있습니다.


### 사망·부활 초상화
모드 경기에서는 서버가 보내는 실제 리스폰 대기 시간(기본 5초)을 본인·팀원 초상화에 표시하며 점진적으로 밝아지는 효과를 적용합니다. 대기 시간은 `server/option.json`의 `respawnSeconds`로 설정합니다. 일반 사망 감지의 3초 표시는 서버 부활 시간을 바꾸지 않는 안내입니다. 자세한 경기 사망·킬러 관전 규칙은 [서버 설명서](#)를 참고하세요.


### 호흡 잔량 표시
호흡 퍼센트는 물에 있을 때만 표시하며, 물 밖에서는 해당 공간을 포션 아이콘에 돌려줍니다.

나침반의 30도 단위 숫자 라벨은 제거했습니다. N·E·S·W는 빨간색, NE·SE·SW·NW는 흰색이며, 현재 방향의 1도 단위 숫자와 눈금은 유지합니다.

커스텀 HUD에서는 바닐라 갑옷·산소 게이지를 숨깁니다. 내 체력바 안쪽 맨 오른편에 `100%` 형식으로 현재 호흡 잔량을 표시하며, 실제 현재/최대 공기량을 기준으로 0–100%로 계산합니다. 포션 효과 아이콘은 이 표시의 왼쪽에 배치됩니다. 호흡 숫자는 검은 외곽선과 파란색 글씨로 표시하고, 커스텀 HUD를 끄면 바닐라 게이지가 다시 표시됩니다.


### 흡수 체력
황금사과 등의 흡수 체력은 본인·팀원·머리 위 체력바에서 일반 체력 뒤에 노란색 구간으로 표시합니다. 막대 안에서 일반 체력과 추가 체력의 비율을 나눠 표시하며, 흡수 체력이 생기거나 소모될 때도 기존의 부드러운 전환과 피해 잔상을 유지합니다. 메인 체력바의 흐르는 사선도 노란 구간까지 이어집니다.
