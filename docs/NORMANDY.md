# 노르망디 공방전

`config/gungang/server/maps/normandy.json`의 `enabled`를 `true`로 설정하고 `/gungang reload`를 실행하면 로비에서 선택할 수 있습니다. 모드는 이 파일을 최초 로딩 때 비활성 예제로 생성합니다. 노르망디 지형이 들어 있는 월드에서 사용하세요. 기존 파일은 덮어쓰지 않습니다.

BRAVO가 공격, ALPHA가 방어합니다. 준비 45초 동안 ALPHA는 자유롭게 이동하면서 무기를 선택할 수 있고, BRAVO는 스폰 구역에서 무기를 선택합니다. 준비가 끝나면 공격팀이 출격하며, 15분 안에 A → B → C → D를 모두 확보하면 BRAVO가 승리합니다. 시간이 끝나면 ALPHA가 승리합니다. 연장전이나 거점 점령 시 시간 추가는 없습니다.

원본 `timer:*` 데이터팩의 규칙과 좌표를 옮겼습니다. 거점 중심 반경 5블록 안에 공격팀만 있으면 매 틱 점령도가 오르며 400틱(20초)에 점령합니다. 양 팀이 있으면 정지합니다. 공격팀이 400틱 동안 없으면 이후 10틱마다 점령도 1이 감소합니다. 점령한 이전 거점은 되찾을 수 없습니다. 사망·관전자 상태는 점령에 참여하지 않습니다.

HUD는 A~D 원형 그래프를 표시하며 현재 거점만 크게 표시합니다. 활성 거점 중앙 블록은 A 파랑/B 연두/C 주황/D 빨강 색유리로 바뀌고, 그 아래 신호기와 3×3 철 블록 받침을 배치합니다. 단계 전환·경기 종료에는 변경 전 블록을 복원합니다. 복원 정보는 월드 저장 데이터에도 보관합니다. 신호기 위는 하늘까지 빛이 통하는 공간이어야 합니다. 거점 영역의 원형 입자는 중심 Y+1.2(기존보다 1블록 높게)에 표시합니다.

| 현재 거점 | 중심 좌표 | 공격팀 부활 좌표 |
|---|---|---|
| A | 17, 4, 222 | 60, 22, 163 |
| B | 6, 16, 282 | -30, 5, 197 |
| C | -25, 18, 333 | -5, 24, 259 |
| D | 40, 12, 330 | 23, 22, 258 |

거점 확보 후 살아 있는 플레이어를 강제 이동하지 않습니다. 다음 부활·도중 참가부터 새 스폰을 사용합니다. 공격팀 부활 시 원본처럼 3초 저항 보호를 적용합니다. 기존 서버 리스폰 시간, 대기 중 무기 변경, 킬러 관전과 `/gungang join BRAVO`, `/gungang stop`을 그대로 사용할 수 있습니다.

맵 JSON의 `timeLimitSeconds`는 전체 제한 시간입니다. `normandy.captureTicks`, `decayDelayTicks`, `decayStepTicks`는 점령·감소 규칙이고, `attackLaunch`는 최초 출격 위치입니다. `points`는 A~D 네 항목으로 각각 `name`, `center`, `radius`, `attackSpawn`을 지정합니다. 위치는 `x/y/z/yaw/pitch` 형식입니다. `alphaSpawn/alphaArea`는 방어팀 스폰, `bravoSpawn/bravoArea`는 공격팀 준비 구역입니다. 전투 중 공격팀 스폰 반경 4블록에서 무기를 바꿀 수 있습니다.

노르망디 맵에는 일반 쟁탈전의 `capture`를 함께 설정하지 마세요. `onPrepare/onStart/onEnd`에 기존 `timer:start`, `timer:stop` 등을 연결하거나 수동 실행하지 마세요. 경기 진행은 모드가 관리합니다. 서버와 클라이언트 모두 새 JAR를 사용하세요.
