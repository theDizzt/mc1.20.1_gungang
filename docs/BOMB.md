# 폭탄전과 데스존

[서버 설정](SERVER.md) · [보조무기](ITEMS.md) · [폭탄전 맵 예제](../server_resource/config/gungang/server/maps/bomb.json)

폭탄전 맵을 선택하면 로비에서 **폭탄전 / 팀 데스매치**를 전환할 수 있습니다. `bomb` 설정이 있는 맵에서만 폭탄전을 사용할 수 있습니다. 기본 예제는 비활성화되어 있습니다. 좌표를 실제 맵에 맞게 바꾸고 `enabled: true`로 설정한 뒤 `/gungang reload`를 실행하세요.

## 라운드 규칙

- 첫 라운드의 공격팀은 ALPHA/BRAVO 중 무작위로 정하며, 이후 매 라운드 공수를 교대합니다.
- 기본 최대 5라운드, 3선승입니다. 매 라운드 30초 준비 후 210초간 진행합니다. 준비 중에는 공격팀만 공격 스폰 영역에 제한되고 방어팀은 이동할 수 있습니다.
- 공격팀 한 명에게 폭탄, 방어팀 한 명에게 해체기를 무작위 지급합니다. 해당 라운드의 보조무기를 대체하며, 담당자는 보조무기를 교체할 수 없습니다. 담당자가 죽거나 접속을 종료하면 같은 팀 생존자에게 넘깁니다.
- 폭탄을 주손에 들고 A/B 지점의 바닥을 조준한 채 우클릭을 4초 유지하면 설치합니다. 보조 손에 있다면 **왼손 아이템 우클릭 후 복귀** 키를 유지해도 됩니다. 4.5블록 이내에서 조준해야 하며, 사용 키를 놓거나 0.35블록보다 멀리 움직이거나 조준을 벗어나면 처음부터 다시 진행합니다.
- 설치 후에는 재설치할 수 없습니다. 45초가 지나면 공격팀이 승리합니다. 폭발은 소리·입자만 재생하며 플레이어나 지형에 피해를 주지 않습니다.
- 해체기 담당자는 설치된 폭탄을 조준하고 우클릭을 7초 유지하면 방어팀 승리입니다. 설치·해체 남은 시간은 기존 보조 체력바에 표시합니다.
- 설치 전에는 상대 팀 전멸로도 승리합니다. 제한시간이 먼저 끝나면 방어팀 승리입니다. 설치 후에는 라운드 제한시간과 전멸로 승패를 결정하지 않고, 폭발 또는 해체로 결정합니다.
- 사망자는 다음 라운드까지 생존한 같은 팀원의 1인칭 시점을 관전합니다. 마우스 휠 위/아래로 이전/다음 팀원을 순환 선택하며, 관전 대상이 죽거나 접속을 종료하면 다른 생존 팀원으로 자동 전환합니다. 적이나 사망자는 선택할 수 없습니다. 팀원이 모두 사망하면 맵의 관전 위치에서 대기합니다. 다음 라운드 또는 경기 종료 시 원래 카메라 모드로 돌아옵니다. TAB을 누른 상태의 휠은 기존 점수판 페이지 전환입니다. 도중 참가자도 다음 라운드부터 플레이합니다. 매 라운드 종료 후 승리 타이틀을 3초 표시하고 다음 준비 단계로 이동합니다.
- 점수 HUD에는 승리 라운드 수와 중앙 타이머 위의 `ROUND 1 / 5` 형식 라운드가 표시됩니다. 각 팀 패널에는 공격 `ATK`(주황)·방어 `DEF`(청록) 태그가 붙습니다. 설치 지점에는 주황색 신호기 빔과 바닥 X가 보이며, 설치된 폭탄 위에는 `45.0초` 형식의 타이머가 표시됩니다.

## 맵 JSON

이탈리아(ID `06`)는 `bomb.areaA` / `bomb.areaB`의 직육면체 영역을 사용합니다. 각 영역은 `minX`, `minY`, `minZ`, `maxX`, `maxY`, `maxZ`로 **설치 가능한 바닥 블록의 범위**를 지정하며 양 끝을 포함합니다. Y가 같은 한 층 영역도 지원합니다. 영역 안에서 조준한 바닥 바로 위의 빈 칸에 설치하고, 한 라운드에 폭탄 하나만 설치할 수 있습니다. 설치·해체 시간과 준비 단계 제한은 기존 규칙대로 적용합니다.

영역을 지정하면 A/B 표시는 가로 중심에 자동 배치되고 주황색 신호기 빔이 표시됩니다. 설치 후 타이머·해체·폭발 효과는 영역 중앙이 아니라 **실제 폭탄 위치**에 적용됩니다. `areaA` / `areaB`가 없으면 기존 한 블록 `pointA` / `pointB` 설정을 그대로 지원합니다.

`timeLimitSeconds`는 **각 라운드의 설치 제한시간**입니다. 기본 210초입니다. `bomb` 내부 설정은 다음과 같습니다.

| 키 | 의미 / 기본값 |
| --- | --- |
| `rounds` | 최대 라운드 수, 5. 1~99의 홀수. 필요한 승수는 `rounds / 2`의 정수 부분 + 1 |
| `swapEveryRounds` | 공수 교대 간격, 1라운드 |
| `preparationSeconds` | 매 라운드 준비시간, 30초 |
| `attackSpawn`, `defenseSpawn` | `x`, `y`, `z`, `yaw`, `pitch` 형태의 공격/방어 스폰 |
| `attackArea`, `defenseArea` | `minX`, `minY`, `minZ`, `maxX`, `maxY`, `maxZ` 형태의 스폰 영역 |
| `pointA`, `pointB` | 정수 `x`, `y`, `z`로 지정하는 폭탄이 놓일 한 블록 좌표 |

설치 지점은 빈 블록이어야 하며, 바로 아래에는 조준할 수 있는 바닥이 있어야 합니다. 빔/X를 표시하기 위해 기존 지형을 바꾸지 않습니다. 폭탄은 설치할 때만 실제 블록으로 배치하며, 해체·폭발·경기 중단 시 제거합니다.

폭탄전 맵에서는 기존 `alphaSpawn`/`alphaArea` 대신 `bomb.attackSpawn`/`attackArea`, `bravoSpawn`/`bravoArea` 대신 `bomb.defenseSpawn`/`defenseArea`를 사용합니다. 팀 데스매치로 전환하면 공격 스폰을 ALPHA, 방어 스폰을 BRAVO 스폰으로 사용하고 팀 데스매치의 시간·킬·리스폰 규칙을 적용합니다.

## 보조무기 JSON

- `config/gungang/server/sub_weapons/98_bomb.json`: `id: "98"`, `plantSeconds: 4`, `fuseSeconds: 45`
- `config/gungang/server/sub_weapons/99_defuser.json`: `id: "99"`, `defuseSeconds: 7`

파일명보다 JSON의 `id`로 구분합니다. 두 ID는 자동 지급 전용이며 플레이어의 선택 목록과 선택 요청에서 제외됩니다. 시간 설정은 경기 시작 시 확정되며 로비에서 `/gungang reload`로 다시 읽습니다. 폭탄은 `gungang:bomb`, 해체기는 `gungang:defuser`입니다. TNT/가위의 바닐라 픽셀 형태를 유지하면서 노란색/빨간색으로 바꾼 텍스처를 사용합니다.

## 모든 맵에서 사용하는 데스존

맵 최상위에 `deathZones` 배열을 추가합니다. 생략하거나 `[]`로 두면 데스존이 없습니다. 맵마다 최대 128개의 직육면체 영역을 지정할 수 있으며 얇은 영역도 가능합니다.

```json
"deathZones": [
  { "minX": -100, "minY": -64, "minZ": -100, "maxX": 100, "maxY": 0, "maxZ": 100 },
  { "minX": 20, "minY": 60, "minZ": 30, "maxX": 25, "maxY": 63, "maxZ": 35 }
]
```

`max`는 각 축의 `min`보다 커야 합니다. 플레이어 몸의 충돌 상자가 영역 내부에 겹치면 즉시 자살 처리합니다. 관전자와 이미 리스폰/라운드 대기 중인 플레이어는 제외합니다. 준비 중에도 적용되므로 스폰 영역과 겹치지 않게 설정하세요. 데스존은 현재 경기 맵의 차원에서만 작동하며, 경기 종료 후에는 작동하지 않습니다.

자살은 사망 수만 증가시키며 적의 처치·어시스트·팀 킬 점수를 올리지 않습니다. 폭탄전은 다음 라운드까지 관전하고, 다른 모드는 기존 리스폰 대기 규칙을 따릅니다. 팀 데스매치로 모드를 전환해도 데스존 목록은 유지됩니다.
