# 홀로그램 영사기

`/give @s gungang:hologram_projector` 또는 GunGang 블록 탭으로 꺼냅니다.

- 블록을 우클릭하면 상자처럼 전용 메뉴가 열립니다. 위쪽 영사 아이템 슬롯에 아이템 1개를 넣으면 홀로그램으로 표시합니다.
- 슬롯의 아이템을 빼거나 다른 아이템으로 바꿀 수 있으며, Shift 클릭으로 빠르게 넣고 뺄 수 있습니다.
- `−` / `+` 버튼으로 크기를 25%~300% 사이에서 25%씩 조절합니다. 기본값은 100%입니다.
- 회전 버튼으로 `OFF → 느리게 → 보통 → 빠르게 → 매우 빠르게`를 순환합니다. 기본값은 보통입니다. 크기와 회전 설정은 즉시 반영되고 저장됩니다.
- 블록을 부수면 보관된 아이템이 함께 떨어집니다. 서버 재시작·청크 재로딩 후에도 보관 상태를 유지합니다.
- 아이템의 이름·인챈트·커스텀 모델 데이터 등 NBT를 보존합니다. 상자와 마찬가지로 실제 아이템을 슬롯에 보관합니다.

표시는 원래 아이템 모델을 사용하며 푸른빛, 천천히 도는 회전, 작은 상하 움직임, 렌즈에서 올라오는 광선과 스캔 링이 적용됩니다. 블록 아이템은 입체로 보이고, 원래 평면 모델인 검·도구 등은 해당 모델의 모양을 유지합니다. 벽 너머로 보이지 않으며 서버와 클라이언트 모두 같은 모드 버전이 필요합니다.

조합은 위 가운데 유리, 가운데 줄 `철 주괴 / 바다 랜턴 / 철 주괴`, 아래 줄 철 주괴 3개입니다.

검증: `gradlew test runServer -PgungangAcidSmoke`, `gradlew runClient -PgungangHologramClientSmoke`. 미리보기: `build/ui-smoke/hologram-projector.png`.
