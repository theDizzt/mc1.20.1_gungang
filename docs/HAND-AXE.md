# 투척용 손도끼 표현

- 근접 공격은 지원하지 않는다. 일반 투척 피해는 66, 헤드샷 피해는 99(1.5배)다. 눈 높이에서 몸 높이의 15% 아래부터 머리 영역으로 판정한다.
- 왼손 아이템 우클릭 후 복귀 매크로 키를 홀드하면 충전하고, 놓으면 투척 후 원래 손으로 복귀한다. 주손에서는 우클릭을 홀드했다 놓아 투척한다. 1인칭과 3인칭의 투척 준비 자세 및 왼손잡이 설정을 지원한다.
- 투척 충전 중 거리 액션바 대신 청록색 예상 궤적과 금색 충돌 지점 표시를 그린다. 서버의 거리·충전 시간·발사각 설정을 아이템 데이터로 전달하며, 이동 속도·중력·공기/물의 감속과 현재 블록/생명체 충돌을 반영한다. 생명체의 미래 이동과 네트워크 지연은 예측하지 않는다. 사용을 놓거나 아이템을 바꾸면 표시가 사라진다.
- 생명체에 맞으면 기존처럼 피해 판정을 한 번 처리하고 사라진다.
- 블록에 맞으면 해당 면에 고정되어 회전과 충돌 판정을 멈춘다. 투척 시 시작된 쿨타임의 남은 시간만큼 유지되며, 저장 후 다시 로드해도 원래 만료 시각을 사용한다.

## 최종 모델 교체

`src/main/resources/assets/gungang/models/item/hand_axe.json`은 Forge OBJ 로더로 같은 폴더의 `hand_axe.obj`와 `hand_axe.mtl`을 사용한다. 손에 든 모델과 투척 모델은 같은 아이템 모델을 사용한다. 손잡이가 Y축, 날이 +X 방향이며, 투척 렌더링에는 `fixed` 표시 설정이 적용된다.

원본 glTF와 텍스처는 `models/hand_axe/`에 보관한다. `scripts/import_hand_axe.ps1 -Archive <zip 경로>`로 다시 변환할 수 있다. 7개 메시, 168개 정점, 84개 삼각형을 보존하고 원본 크기를 0.47배로 줄였다. glTF의 반복 UV가 Minecraft 텍스처 아틀라스 밖으로 나가지 않도록 원본 텍스처를 3×3으로 타일링하고 UV를 재배치한다. 투명한 날 부분에는 cutout 렌더링을 적용한다. 모델 자체의 날은 원본처럼 매우 얇다.

## 게임 내 확인

양손 설정에서 근접 공격이 차단되는지, 매크로 키 홀드/해제로 투척과 복귀가 되는지 확인한다. 일반 명중 66과 헤드샷 99 피해 및 투척 준비 자세를 확인한다. 벽/바닥/천장에 던져 정지 방향과 쿨타임 종료 시 제거를 확인하고, 생명체 명중 시 기존 피해와 즉시 제거를 확인한다. 전용 서버의 다른 플레이어에게도 동일하게 표시되는지 확인한다.
