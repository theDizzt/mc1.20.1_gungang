## 레드스톤 연결형 셔터

`/give @s gungang:shutter` 또는 GunGang 블록 탭에서 꺼냅니다. 철 주괴 6개를 가로 3칸 × 세로 2칸으로 조합하면 셔터 6개를 얻습니다.

- 한 블록 크기의 패널이며 두께는 마인크래프트 문과 같은 **3/16블록**입니다. 설치할 때 보는 방향에 따라 평면이 정해지며, 기존 셔터의 위·아래·옆면에 이어 붙이면 같은 평면을 따릅니다.
- 같은 평면에서 가로·세로로 맞닿은 패널이 하나의 셔터가 됩니다. 내부 테두리는 사라지고 외곽 가이드와 상단 덮개만 남습니다. 앞뒤로 나란한 셔터와 직각 방향 셔터는 별개입니다.
- 연결된 패널 중 한 곳이라도 주변 레드스톤 신호를 받으면 전체가 위로 열립니다. 모든 신호가 꺼지면 아래로 닫힙니다. 높이 1블록당 약 1초이며, 이동 중 신호가 바뀌면 현재 위치에서 반전합니다.
- 금속 판이 상단으로 올라가며 사라지는 애니메이션과 작동·정지 소리가 나옵니다. 소리는 연결 그룹당 한 곳에서 재생하며 게임의 **블록 소리** 볼륨을 따릅니다.
- 실제 통과 공간도 애니메이션 높이에 맞춰 아래부터 열립니다. 완전히 열리면 외곽 가이드와 상단 덮개만 남습니다. 열린 패널도 조준해 부술 수 있으며, 연결 부분을 제거하면 나뉜 그룹은 각각 신호를 확인합니다.
- 진행 중 위치와 신호 상태는 저장되며, 서버와 클라이언트에 같은 버전이 필요합니다.
- AI 봇은 닫힌 셔터를 막힌 길로 인식하며, 경로가 셔터를 지나야 하면 근처(가로 8·세로 4블록 이내)의 레버·버튼을 직접 조작해 엽니다. 자세한 동작은 [봇 맵 경로망](BOTS.md#navigation)을 참고하세요.
- `/gungang reset`, 게임·라운드 시작/종료 시 기존 맵 기믹 초기화와 함께 레버는 OFF, 셔터는 즉시 완전히 닫힌 상태가 됩니다. 당시 로드되지 않은 청크도 다음 로드 시 적용됩니다. 이후 새로운 레드스톤 신호에는 정상 반응합니다.

검증: `gradlew test runServer -PgungangShutterSmoke`, `gradlew runClient -PgungangShutterClientSmoke`. 화면 비교는 `build/ui-smoke/shutter-states.png`에 생성됩니다.

## 로비·장비·팀 선택·회복 블록

서버와 클라이언트에 같은 버전의 모드를 설치하세요. 크리에이티브의 GunGang 블록 탭 또는 `/give @s gungang:<아이디>`로 꺼낼 수 있습니다.

| 아이디 | 우클릭 / 밟기 |
| --- | --- |
| `war_table` | 로비를 열고 자신의 로비 화면 표시. 다른 플레이어의 팀을 초기화하지 않음 |
| `armory` | 무기 선택 화면. 경기 중에는 무기고 3블록 이내에서 선택 가능 |
| `alpha_team` | ALPHA 팀 선택 |
| `bravo_team` | BRAVO 팀 선택 |
| `small_health_pack` | 밟으면 35 회복, 10초 쿨타임 |
| `large_health_pack` | 밟으면 70 회복, 15초 쿨타임 |

팀 변경과 로비 열기는 경기 전 로비에서 가능합니다. 팀 블록의 색상은 `server/option.json`의 팀 색상을 따릅니다. 서 있는 동안 화면이 반복해서 열리지 않으며, 블록에서 내려왔다가 다시 밟거나 우클릭하면 다시 열 수 있습니다.

전쟁 탁자와 무기고에는 `models/war_table`, `models/armory`의 모델/텍스처를 사용합니다. 전쟁 탁자는 설치 위치를 중심으로 3×1×3, 무기고는 정면 기준 너비 2×높이 3×깊이 1칸을 차지합니다. 플레이어를 향해 설치되고 필요한 모든 공간이 비어 있어야 합니다. 어느 부분을 눌러도 같은 기능이 열리며, 일부를 부수면 전체가 제거되고 아이템은 하나만 떨어집니다. 이전 버전의 단일 블록으로 설치한 탁자/무기고는 부순 뒤 다시 설치하세요. 원본 모델을 수정했다면 `python scripts/import_station_models.py`로 리소스를 다시 생성할 수 있습니다.

소형 팩은 다이아몬드 블록 위 파란 포션, 대형 팩은 에메랄드 블록 위 큰 초록 포션으로 표시합니다. 사용하면 해당 위치의 블록이 색유리 모습으로 바뀌고 소수점 한 자리의 남은 시간이 표시됩니다. 포션/숫자는 카메라를 향하며 벽 뒤에서 보이지 않습니다. 두 팩 모두 광원 밝기 15입니다.

쿨타임은 **설치된 블록별**로 저장합니다. 같은 블록을 사용하는 모든 플레이어가 그 블록의 쿨타임을 공유하며 다른 위치의 팩에는 영향을 주지 않습니다. 청크 재로드와 서버 재시작 시 보존되며, 서버가 꺼져 있는 시간은 진행되지 않습니다. 최대 체력인 플레이어는 팩을 소비하지 않습니다. 관전자와 리스폰 대기자는 사용하지 못합니다.

`config/gungang/item/small_health_pack.json`:
```json
{ "heal": 35, "cooldownSeconds": 10 }
```

`config/gungang/item/large_health_pack.json`:
```json
{ "heal": 70, "cooldownSeconds": 15 }
```

설정을 수정한 뒤 로비에서 `/gungang reload`를 실행하세요. 이미 진행 중인 쿨타임은 유지되고 다음 사용부터 새 값이 적용됩니다.

## 팀 스폰 홀로그램 출입구

```text
/give @s gungang:alpha_spawn_gate
/give @s gungang:bravo_spawn_gate
```

GunGang 블록 탭에서도 꺼낼 수 있습니다. 출입구 전체를 이 블록으로 채우세요. 각 블록은 1×1×1이며 인접한 같은 종류의 면은 합쳐 보입니다. 반투명 격자·움직이는 빛줄기로 표시하며 팀 색상은 `server/option.json`의 팀 색상을 따릅니다.

살아 있는 해당 팀 플레이어는 양방향으로 통과합니다. 상대 팀·미배정 플레이어·일반 엔티티는 막힙니다. 관전자 모드의 기본 비충돌 이동은 유지됩니다.

총알과 투사체는 발사한 팀과 무관하게 막힙니다. TaCZ 총알은 출입구 충돌 시 제거하며 관통 피해도 취소합니다. 출입구를 가로지르는 공격, 폭발 피해·넉백·블록 파괴, 해로운 물약 효과를 차단합니다. 모드의 화염병·가스/불발탄·산성 노즐 피해도 출입구를 가로질러 전달되지 않습니다. 같은 쪽에서 발생한 공격은 정상 적용됩니다.

출입구는 폭발과 피스톤에 의해 파괴·이동되지 않습니다. 건축 시 크리에이티브 모드로 제거할 수 있습니다.

## 폭발물·파괴 벽·웅덩이·유체·노즐

모든 기믹은 `gungang:` 네임스페이스를 사용합니다. 크리에이티브 GunGang 블록 탭 또는 `/give @s gungang:uxo`처럼 지급해 설치합니다. 설정은 서버의 `config/gungang/item/<아이템 ID>.json`이며, 없는 파일은 시작 시 생성됩니다. 수정 후 `/gungang reload`를 실행합니다. 제공 예제는 [item 폴더](server-examples/config/gungang/item)에 있습니다.

| ID | 동작 및 기본 설정 |
| --- | --- |
| `uxo` | 누구나 밟으면 폭발. `damage: 80`, `radius: 5`, `respawnSeconds: 30` |
| `gas_barrel` | 빨간 주의 표지 드럼통, 높이 1.5블록. 위·아래 어디를 공격해도 폭발. UXO와 같은 폭발 설정 |
| `cracked_oak_planks` | 파괴 가능한 나무판자, `health: 100` |
| `cracked_glass` / `cracked_glass_pane` | 파괴 가능한 유리/유리판, `health: 60` / `40` |
| `cracked_<색상>_concrete` | 바닐라 16색 콘크리트 각각 별도 설정, `health: 200` |
| `puddle` | 흐르지 않는 1/16 높이 물. 닿으면 불이 꺼집니다. `soundVolume: 0.7`, `soundIntervalTicks: 6` |
| `acid_puddle` | 흐르지 않는 1/16 높이 산성 용액. 닿으면 산성 용액과 같은 독(`acid.json`)에 걸립니다. 소리 설정은 `puddle.json`을 따릅니다 |
| `acid` / `acid_bucket` | 빛나는 연두색 유체. 일반 빈 양동이로 원천을 퍼 담으면 `산성 액체가 든 양동이`가 되며, 비우면 일반 양동이로 돌아옵니다. 산성 양동이는 크리에이티브 GunGang 아이템 탭에 표시됩니다. 효과는 `acid.json`에서 `poisonSeconds: 8`, `amplifier: 0` |
| `nozzle` | 물·용암·산성액체와 같은 칸에 설치 가능한 얇은 쇠 기둥. 바닐라 물 잠김처럼 해당 칸에 원천을 보존하며, 빈 양동이로 액체만 회수하거나 채울 수 있습니다. 위로 물 입자 분사. 분사 기둥에 닿은 불붙은 개체의 불을 끕니다. `height: 3`, `particlesPerSecond: 40` |
| `acid_nozzle` | 노즐과 같지만 형광 연두색 산성 입자를 분사합니다. 분사 기둥에 닿은 생명체는 팀 구분 없이 피해를 받습니다. `height: 3`, `particlesPerSecond: 40`, `damage: 2`, `damageIntervalTicks: 10` |

폭발은 팀을 구분하지 않고 반경 안 플레이어에게 동일한 기본 피해를 줍니다. 방어구 등 피해 감소는 적용됩니다. 주변 지형을 없애지 않습니다. 재생성 시간은 서버 게임 시간 기준입니다.

벽은 근접 공격·화살·TaCZ 총알로 피해를 받고, HP가 소진되면 외형과 충돌이 사라집니다. `/gungang reset`, 경기 준비·종료 시 설치 위치와 HP를 복구합니다. 청크가 내려가 있던 벽도 다시 로드될 때 복구됩니다. 크리에이티브로 직접 제거한 블록은 복구하지 않습니다. `/gungang cleardeployables`는 기믹을 복구하지 않습니다.

울타리·계단·유리판·철창은 물처럼 산성 용액과 같은 칸에 겹쳐 둘 수 있습니다(산성 양동이로 채우거나 산성액 안에 설치하거나 흐르는 산성액이 유입). 빈 양동이로 산성 용액만 회수됩니다. 산성액 원천 둘 사이의 흐르는 액체는 바닥이 받쳐 주면 물처럼 원천으로 합쳐집니다.

산성 액체와 산성 웅덩이는 일반 독과 별도인 `산성 독`을 부여합니다. 기본값은 원래 독 속도인 25틱(1.25초)마다 피해 8이며, 체력 1에서 멈추는 제한 없이 사망까지 피해를 줍니다. `acid.json`의 `poisonSeconds`는 접촉이 끝난 뒤 지속 시간(기본 8초)이며, `amplifier` 0/1/2/3/4의 피해 간격은 각각 25/12/6/3/1틱입니다. 우유로 해제할 수 있으며 소품으로 변신한 숨는 플레이어의 면역은 유지됩니다.

웅덩이·산성 웅덩이 아이템으로 울타리·유리·유리판을 클릭하면 해당 블록을 유지한 채 겹쳐 설치합니다. 겹친 웅덩이는 크리에이티브 공격으로 제거할 수 있습니다. 첨벙 소리는 모드의 발소리 음량·차폐 설정을 따릅니다.

산성액체 원천은 맵 제작 시 `/setblock ~ ~ ~ gungang:acid`로 배치할 수 있습니다. 저장된 양동이의 호환성과 담긴 상태 표현을 위해 `gungang:acid_bucket` ID는 유지합니다.

노즐 입자는 4틱마다 묶음 정보 하나를 보내고 클라이언트에서 생성합니다. 기본 초당 40개 설정은 유지하면서 노즐당 초당 전송 횟수를 40회에서 5회로 줄였습니다. 피해·소화 판정은 서버가 처리합니다. 이 묶음 전송을 사용하는 버전은 서버와 클라이언트를 함께 업데이트해야 합니다.

Oculus/Iris에서는 활성 쉐이더팩의 물 재질 ID를 산성액체에 연결합니다. 팩이 산성액체 전용 재질을 지정했다면 그 설정을 우선합니다. 실제 반사·굴절·색상은 쉐이더팩에 따라 달라집니다. OptiFine 등 다른 쉐이더 구현은 팩의 `shaders/block.properties`에서 `minecraft:water`가 속한 `block.<번호>` 항목에 `gungang:acid`를 추가해야 합니다.

## 호위 경로 지정 블록

| ID | 표시·용도 |
| --- | --- |
| `escort_path` | 초록: 곡선·경사 경로 포인트 |
| `escort_start` | 빨강: 수레 중심 기준 시작점 |

<a id="death-zone"></a>

## 데스존 영역 지정 블록 (u223)

`gungang:death_zone`은 경기용 데스존을 지정하는 블록입니다. 크리에이티브 GunGang 블록 탭이나 `/give @s gungang:death_zone`으로 꺼냅니다.

- 방벽처럼 보이지 않는 블록입니다. 이 블록을 주 손이나 보조 손에 들고 있을 때만 각 칸에 해골 표시가 보이고, 선택·파괴(크리에이티브)할 수 있습니다.
- 방벽과 달리 충돌 판정이 없습니다. 플레이어·봇·총알·클릭이 모두 통과하며 빛과 시야도 막지 않습니다. 몹이 스폰하지 않고, 서바이벌에서 부술 수 없으며 드롭이 없습니다.
- 경기 준비·진행 중 참가자(양 팀 플레이어와 AI 봇)의 몸이 이 칸에 겹치면 즉시 사망(자살 처리)합니다. 경기 밖에서는 아무 효과가 없습니다. 봇은 경로를 계산할 때 이 칸을 치명적인 지형으로 보고 피합니다.
- 기존 맵 JSON의 `deathZones` 영역은 더 이상 작동하지 않습니다. 이전 영역 자리에 이 블록을 설치하세요. → [데스존 규칙](GAMEPLAY.md#bomb)
- 숨바꼭질 196번 변신 블록이기도 합니다. 변신하면 술래에게는 보이지 않고 같은 팀에게만 해골 표시가 보이며, 닿은 술래는 즉시 사망합니다.

<a id="desk-blocks"></a>

## 탁상 시계·돈을 실은 수레 (u247)

- `gungang:desk_clock`(탁상 시계): 설치할 수 있는 LCD 탁상 시계입니다. 화면에 **실제 컴퓨터 시각**을 24시간 `HH:MM:SS`로 표시하며(경기 타이머와 같은 숫자 아틀라스, 꺼진 세그먼트 표시, 매초 깜빡이는 콜론), 어두운 곳에서도 빛납니다. 우클릭으로 알람을 켜고 끄며, 켜진 동안 화면이 빨갛게 바뀌고 계속 알람음(삑 4번 후 쉼)이 울립니다. 설치 방향을 따릅니다. 숨바꼭질 221번 변신 블록에서는 E로 알람을 켜고 끕니다.
- `gungang:money_cart`(돈을 실은 수레): 에메랄드 돈뭉치와 금괴를 가득 실은 손수레 장식 블록입니다. 숨바꼭질 222번 변신 블록에서는 이동속도 2.4배로 움직이며 돈을 흘리고, E로 현금 인출기 소리를 냅니다.

## 캡슐 뽑기 기계·이젤·정원 분수·어항·에러 블록 (u263, u267, u269)

- `gungang:capsule_machine`(캡슐 뽑기 기계): 아래는 본체, 위는 캡슐이 든 유리 돔인 2블록 높이 블록입니다. 서바이벌에서 부술 수 없고, 한쪽을 없애면 다른 쪽도 사라집니다. 경기 밖에서 어느 쪽이든 우클릭하면 숨바꼭질 블록 목록 UI가 열립니다(경기 중에는 열리지 않음). 이 UI로 한 변신은 경기 시작·로비 초기화 때 풀립니다. 숨바꼭질 232번 변신 블록도 이 블록입니다. u267에서 이전의 1칸짜리 캡슐 기계를 없앴으므로, 그때 설치한 블록은 위쪽 반이 없으니 다시 설치하세요. u269부터 유리 돔은 반투명한 흰 색유리라 안의 캡슐이 잘 보입니다.
- `gungang:easel`(이젤): 폭 2블록·높이 2블록입니다(u267). 설치하면 네 칸을 차지하고 아무 칸이나 부수면 전체가 사라집니다. 어느 칸을 우클릭해도 16×16 그림 그리기 화면이 열리며, 캔버스도 커진 판에 맞게 그립니다. 숨바꼭질 241번입니다.
- `gungang:garden_fountain`(작은 정원 분수): 2×2 크기·높이 2블록의 3단 사암 분수입니다(u267). 팔각 받침, 고리 달린 기둥, 물이 담긴 넓은 아래 그릇, 가운데 기둥, 가운데·맨 위 그릇과 파인애플 모양 꼭대기로 이루어지며, 꼭대기에서 물이 솟고 세 그릇 가장자리에서 물방울이 떨어집니다. 여덟 칸을 차지하고 아무 칸이나 부수면 전체가 사라집니다. 숨바꼭질 235번입니다. u269에서 그릇 가장자리가 없는 텍스처(보라·검정 체크)로 보이던 문제를 고쳤습니다(매끄러운 사암 윗면 텍스처 사용).
- 이젤·분수 아이템 아이콘은 u269부터 모델의 실제 중심에 맞춰 인벤토리·블록 목록 칸 안에 들어오게 그립니다(손에 들거나 바닥에 떨어진 모습도 같은 기준).
- `gungang:aquarium`(어항): 물이 든 유리 수조입니다. 옆이나 위아래에 붙인 어항끼리는 유리·물 면 없이 하나로 이어집니다. 우클릭으로 꾸밉니다.
  - 모래·붉은 모래 / 자갈: 바닥재
  - 조약돌·돌·이끼 낀 조약돌·안산암·화강암·섬록암·응회암: 돌무더기
  - 해초·켈프: 흔들리는 수초
  - 물고기 양동이(대구·연어·열대어·복어): 물고기를 넣고 빈 물 양동이를 돌려받음. 빈 양동이로 다시 꺼낼 수 있음
  - 물고기·오징어 스폰알(대구·연어·열대어·복어·오징어·발광 오징어, u269): 어항 안 물고기 모습만 바뀌며 **실제 엔티티는 생기지 않습니다.** 동물 스폰이 막힌 서버에서도 쓸 수 있습니다. 서바이벌에서는 스폰알 1개를 씁니다. 발광 오징어는 오징어 모습으로 표시됩니다
  - 먹물 주머니·발광 먹물 주머니: 작은 오징어
  - 빈손으로 웅크리고 우클릭: 모두 비움
  - 어항 속 물고기는 블록 상태로만 저장되는 표시용 모델이라 엔티티 수·몹 스폰 규칙과 무관합니다. u269에서 바닥재·돌이 텍스처가 찌그러진 줄무늬로 보이거나 물에 가려 안 보이던 문제를 고쳤고, 아이콘도 물·모래·수초·물고기가 든 수조 모양으로 바꿨습니다. 숨바꼭질 224번입니다.
- `gungang:error_block`(에러 블록): 텍스처 없음을 흉내 낸 보라·검정 체크 블록입니다. u269부터 평소에는 그대로 있다가 불규칙한 간격으로 줄 밀림·RGB 색 분리·색 반전 띠·노이즈 줄·화면 찢김 글리치가 잠깐씩 끼어드는 애니메이션 텍스처입니다. 숨바꼭질 234번입니다.
- 이젤·분수는 여러 칸 블록 공용 클래스 `MultiPartBlock`을 씁니다. 0번 칸이 모델 전체와 블록 엔티티를 맡고 나머지 칸은 충돌만 담당합니다. u267 이전에 설치한 이젤·분수는 1칸 블록이라 충돌·제거가 올바르지 않으므로 지우고 다시 설치하세요.
