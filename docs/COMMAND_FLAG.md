# 지휘 깃발

- 보조무기 ID: `75`, 아이템: `gungang:command_flag`
- 설치형, 설치 시 쿨타임 75초 시작, 깃발 체력 100
- 우클릭으로 미리보기를 켠 뒤 우클릭 또는 기존 설치 단축키로 설치한다.
- 5블럭 이내의 블럭·반블럭 윗면에 설치하며, 높이 2.5블럭의 빈 공간이 필요하다.

| 생존 시간 | 회복 | 효과 반경 | 추가 효과 |
|---|---|---|---|
| 0~19초 | 초당 1 | 10블럭 | 없음 |
| 20~59초 | 초당 5 | 20블럭 | 없음 |
| 60~179초 | 초당 5 | 40블럭 | 받는 피해 15% 감소 |
| 180초 이상 | 초당 5 | 거리·차원 제한 없음 | 받는 피해 15% 감소 |

회복과 피해 감소는 살아 있는 아군 플레이어에게 적용된다. 범위는 깃발 위치로부터의 거리이며, 여러 깃발이 겹치면 가장 강한 회복과 피해 감소 한 번만 적용된다. 깃발이 파괴되거나 정리되면 효과가 즉시 사라진다. 다른 설치물과 함께 소유자 정리 및 경기 초기화에 연결된다.

참고 이미지의 나무 기둥, 가로 봉, 뾰족한 천, 밝은 테두리와 받침을 블럭형 모델로 구성했다. 설치된 알파·브라보 깃발에는 왕관 대신 해당 팀 로고를 양면으로 표시하며, 미배정 팀은 왕관을 유지한다. 천·범위 파티클·발광 윤곽은 설치 당시 팀 색상으로 표시한다. 깃발은 아군과 적 모두에게 발광한다. 인벤토리 모델의 천은 현재 플레이어 팀 색상을 사용한다.

설치자의 보조 체력바에 각 깃발의 체력과 생존 시간을 표시한다. 보조 체력바 글꼴은 `gungang_ui`의 GUNGANG → Galmuri11 Bold 순서로 사용한다.

깃발의 청크는 생존 중 유지되며 제거 시 해제된다. 서버 재시작 시 깃발은 저장하지 않는다.

## 스펙 조정

`/gungang modify ui` → 보조무기 → `75 지휘 깃발`의 아이템 효과 설정에서 조정한다. 기존 설정 UI와 동일하게 로비에서 저장하며, 새로 설치하는 깃발은 저장된 설정을 사용한다. 장비 쿨타임은 재지급·재선택부터 적용된다. 설명·사용법·표시 스탯은 같은 화면의 표시 항목에서 별도로 수정한다.

저장 파일: `config/gungang/item/command_flag.json`

| 항목 | 기본값 |
|---|---:|
| health · 깃발 최대 체력 | 100 |
| cooldownSeconds · 설치 쿨타임 | 75초 |
| placementRange · 설치 거리 | 5블록 |
| baseRadius · 기본 반경 | 10블록 |
| baseHealPerSecond · 기본 초당 회복 | 1 |
| healingUpgradeSeconds · 회복 강화 생존 시간 | 20초 |
| upgradedHealPerSecond · 강화 초당 회복 | 5 |
| healingRadius · 회복 강화 반경 | 20블록 |
| defenseUpgradeSeconds · 피해 감소 생존 시간 | 60초 |
| defenseRadius · 피해 감소 단계 반경 | 40블록 |
| damageReductionPercent · 피해 감소율 | 15% |
| globalUpgradeSeconds · 전체 아군 적용 생존 시간 | 180초 |

단계 시간은 모두 설치 시점 기준이며 회복 강화 ≤ 피해 감소 ≤ 전체 적용 순서여야 한다. 보조 체력바의 최대 체력·범위·전체 적용 시간도 실제 설정값을 사용한다.

## 숨바꼭질 244번 블록

- gungang:command_flag_block: 지휘 깃발 모델의 장식용 블록. 기존 보조무기(gungang:command_flag)와 별개입니다.
- 숨바꼭질 변신 체력 255. E키로 16가지 색상을 순환합니다. 설치한 블록은 우클릭으로 색상을 변경합니다.
- 색상과 방향은 블록 상태로 저장·동기화됩니다. 보조무기의 회복·피해 감소 효과는 없습니다.
- 기존 gungang:mirror 아이템은 제거되며, 월드의 거울 블록은 청크가 로드되어 틱 처리될 때 드롭 없이 자동 제거됩니다. 미로드 청크를 강제로 불러오지는 않습니다.
