# 체력 재생과 플레이어 넉백 (u143)

자동 재생은 피해 후 100틱(5초)에 체력 1을 회복하고, 이후 20틱마다 1씩 회복한다. 다시 피해를 받으면 100틱 대기를 새로 시작한다. 서버 TPS가 20보다 낮으면 실제 시간도 그만큼 길어진다.

바닐라 자동 회복의 세 경로를 별도로 차단한다.

- 허기·포만감: `FoodRegenerationMixin`
- 재생 상태 효과: `RegenerationEffectMixin`
- 평화로움 난이도의 `Player.aiStep` 회복: `PeacefulRegenerationMixin`

평화로움의 회복은 허기 코드와 별도이므로 기존 두 차단만으로는 초당 1 회복이 중첩될 수 있었다. 힐팩·회복약·거점 등 명시적인 회복 기능은 유지한다.

`LivingEntity.knockback`으로 실제 속도가 변한 서버 플레이어에게는 자신의 연결로 이동 속도 패킷을 즉시 보낸다. 이벤트 취소나 넉백 저항 때문에 속도가 바뀌지 않았다면 추가 패킷을 보내지 않는다. 숨바꼭질 마인카트·자석의 직접 속도 변경에도 같은 전달 경로를 적용한다. 총기별로 설정된 넉백 강도나 고정·기절 규칙은 변경하지 않는다.

검증: `gradlew.bat -PgungangPropSmoke runServer`. 평화로움·보통에서 포만감/재생 효과/중복 회복 콜백을 함께 적용해 0~160틱 매 틱 체력을 확인하고, 재피격 대기·명시적 회복·넉백 패킷·완전 넉백 저항을 검사한다. 배포 JAR에는 검증 클래스가 포함되지 않는다.
