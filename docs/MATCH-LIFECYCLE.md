# 경기 정리·회복·명령어형 보조무기

[README·문서 안내](../README.md) · [서버 경기 흐름](SERVER.md) · [아이템 설정](ITEMS.md) · [명령어](COMMANDS.md)

경기 준비 시작, 실제 전투 시작, 경기 종료에 모든 지뢰와 방벽을 제거합니다. 로드되지 않은 청크의 설치물 기록도 무효화하여 다시 로드될 때 제거합니다. 관리자 명령 `/gungang cleardeployables`로도 전체 제거할 수 있습니다.

지뢰는 플레이어별 최대 3개(`item/landmine.json`의 `maxPlaced`로 더 낮게 제한 가능), 방벽은 플레이어별 1개입니다. 설치물 외곽선에는 설치 당시 팀 RGB 색상이 표시됩니다. 스코어보드 팀 Red는 ALPHA, Blue는 BRAVO 설정 색상을 따릅니다.

경기 준비 시작과 실제 전투 시작에는 참가자 인벤토리(방어구·보조 손·커서 포함)를 비우고 선택한 주무기·보조무기와 `server/slot9.json`의 아이템을 재지급합니다. 종료에는 인벤토리를 비우고 slot9 아이템만 지급합니다. 시작 전 아이템을 복원하지 않습니다. 엔더 상자와 월드 상자 내용은 초기화 대상이 아닙니다. 주무기/보조무기를 선택할 때도 9번 슬롯을 다시 지급합니다.

생존/모험 플레이어는 피해를 받은 뒤 5초가 지나면 체력 1을 회복하고, 이후 피해가 없으면 1초마다 1씩 회복합니다. 바닐라 허기 기반 자연 회복은 비활성화하며 회복약·포션의 직접 회복은 유지합니다. 관전·리스폰 대기·크리에이티브 상태에서는 자동 회복하지 않습니다.

보조무기 JSON에서 `itemNbt`(별칭 `nbt`)가 생략되거나 빈 문자열/`{}`이면 `command`를 실행합니다. NBT가 있으면 아이템 지급이 우선합니다. **사용 버튼을 누를 때가 아니라 장비를 지급·재지급하거나 선택할 때** 실행됩니다. 명령은 서버 설정에 작성하며 해당 플레이어의 위치·차원·`@s`를 기준으로 권한 레벨 2로 실행합니다. 함수 호출도 가능합니다.

```json
{
  "id": "command_snowball",
  "itemNbt": "",
  "command": "item replace entity @s weapon.offhand with minecraft:snowball 1",
  "name": "명령어 눈덩이",
  "description": "명령어로 보조 손에 지급",
  "usage": "보조무기 사용 키",
  "category": "투척",
  "cooldownSeconds": 3
}
```

명령 실행 뒤 보조 손에 있는 아이템에는 기존 보조무기 수량 유지·쿨타임 설정을 적용합니다. `give`로 일반 인벤토리에 넣은 아이템까지 자동으로 보조무기로 처리하지는 않습니다. 주무기와 slot9는 `itemNbt`를 사용해야 합니다. 기존 보조무기 JSON의 빈 `command` 항목은 실행되지 않습니다.

상단 점수 HUD와 타이머는 이전의 80% 크기로 줄였으며, 다른 보스바가 없으면 상단 2 GUI 픽셀부터 배치합니다.
