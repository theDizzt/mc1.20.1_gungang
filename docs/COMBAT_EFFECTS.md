# 전투 효과와 보조무기 조작

- 터렛: 발포음 재생 볼륨을 0.55에서 1.1로 높였습니다.
- ARC-12: 직접 피격과 연쇄 감전에 기존 발광 효과, 약한 밀침, 0.3초 시점 회전 잠금을 적용합니다. 사망·관전 상태에서는 잠금이 해제됩니다.
- 보조 체력바: 게이지와 아이콘·숫자를 유지하고 불투명 배경 판을 제거했습니다.
- 송풍기: 일반 바람과 공기 대포의 밀침이 바람의 3차원 방향을 따릅니다. 위아래로도 밀 수 있으며, 일반 엔티티에도 이동 효과를 적용합니다. 고정 설치물처럼 자체적으로 이동을 막는 엔티티는 이동하지 않습니다.
- 헤르메스 부츠: G(보조무기 공격 키)로 시선 방향 대쉬. 위아래 시선도 반영합니다. 이동키 더블탭의 기존 수평 8방향 대쉬도 유지합니다. 충전과 쿨타임은 공통입니다.
- 수리검: 피해가 적용되면 투척자에게 명중 확인음을 재생합니다. 피해에 따른 기본 넉백과 보정 넉백은 적용하지 않습니다.

헤르메스 방향 패킷과 감전 패킷 변경으로 네트워크 버전을 5로 올렸습니다. 서버와 클라이언트를 함께 업데이트해야 합니다.
