# LAS-5 (주무기 ID 27)

`zeta:las_5`를 사용합니다. TaCZ와 해당 총기 팩이 필요합니다.

발당 기본 피해는 `2 × (1 + 현재 과열값 / 최대 과열값)`입니다. 비율을 0~1로 제한하므로 피해는 2~4입니다. 서버가 탄환 생성 시 과열값을 저장해, 발사 후 냉각·재장전·무기 교체로 이미 발사된 탄환의 피해가 바뀌지 않습니다.

| 과열 | 발당 피해 | 초당 20발 명중 시 DPS |
| --- | --- | --- |
| 0% | 2 | 40 |
| 59% | 3.18 | 63.6 |
| 100% | 4 | 80 |

이는 헤드샷·방어·전투자극제 적용 전 수치입니다. 과열 잠금 중에는 기존 총기 규칙에 따라 발사가 중단되므로 80 DPS는 계산상의 상한입니다. 기존 팩의 1200 RPM, 냉각과 과열 잠금 규칙은 유지합니다.

등록 파일: `config/gungang/server/weapons/27_las-5.json`. 서버 예제에도 같은 파일을 제공합니다. 기존 서버에는 해당 JSON을 추가한 뒤 `/gungang reload`로 목록을 갱신합니다. 피해 코드 변경은 모드 교체 후 서버 재시작이 필요합니다.
