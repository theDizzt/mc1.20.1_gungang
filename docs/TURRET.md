# 터렛 (보조무기 ID 90)

터렛은 빈 **2×2×2블록 공간**에 설치하는 자동 사격 장비입니다. 보조무기 사용 후 우클릭으로 설치하고 좌클릭으로 취소합니다. 네 바닥 블록 모두 윗면이 단단해야 하며, 물속·공중·천장이 낮은 곳·다른 개체와 겹치는 곳에는 설치할 수 없습니다. 바닥이 제거되면 터렛도 철거됩니다.

| 항목 | 기본값 |
| --- | --- |
| 쿨타임 | 설치 성공부터 210초 |
| 감지 반경 | 16블록 |
| 표적 | 시야가 확보된 가장 가까운 적 플레이어 또는 봇 |
| 피해 | 발당 10, 방어구·방패 등 기존 피해 규칙 적용 |
| 발사 간격 | 5틱, 초당 4발 |
| 탄약 | 250발 |
| 체력 | 100 |
| 최대 설치 | 설치자당 1개 |
| 재장전 | 설치자만, 외곽에서 3블록 이내, E(인벤토리 키) 유지, 초당 20발 |

적이 벽이나 다른 개체에 가려지면 사격하지 않습니다. 아군·설치자·관전자·크리에이티브 플레이어·비무장 지대와 보호 중인 대상은 공격하지 않습니다. 준비 중인 경기에서도 사격하지 않습니다. 처치와 피해량은 설치자에게 귀속됩니다.

탄약이 0이 되어도 터렛은 남으며, 본체 위로 회색 연기가 계속 발생해 탄약 소진 상태를 알립니다. 재장전으로 1발 이상 채워지면 새 연기 발생이 멈추고 남은 연기는 자연스럽게 사라집니다. 일부만 소모했을 때도 장전할 수 있으며, 장전 중에는 사격이 멈춥니다. E를 놓거나 거리가 멀어지거나 벽에 가려지거나 화면을 열면 장전이 중단됩니다. 가득 찼을 때 초과 장전하지 않습니다. 별도 탄약 아이템은 필요 없습니다. 0발부터 완충까지 12.5초입니다.

설치자에게 `터렛 탄약 250/250` 보조 체력바가 표시되고, 0발일 때도 표시됩니다. 가까이 가면 재장전 키 안내가 나타납니다. E를 재지정했다면 인벤토리 키 설정을 따릅니다. 재장전 중에는 E가 무기 선택 화면을 열지 않습니다.

설치자 사망·로그아웃·차원 이동에 따른 소유자 소실, 보조무기 변경, 경기 정리, 청크 언로드 시 철거됩니다. 철거·파괴 후에도 설치 쿨타임은 유지됩니다. 서버 재시작 후 설치물은 복원하지 않습니다. 봇은 공격 대상에 포함되지만, 터렛의 자동 선택·설치·재장전 AI는 제공하지 않습니다.

## 설정

신규 서버 또는 `/gungang reload` 시 없는 파일을 생성합니다. 기존 ID 90 사용자 정의 무기를 덮어쓰지 않으므로 이미 해당 ID가 있으면 제공된 예제와 비교해 교체하세요.

- `config/gungang/server/sub_weapons/90_turret.json`: 보조무기 등록·설명.
- `config/gungang/item/turret.json`: 피해·감지 반경·체력·탄약·발사 간격·재장전 속도·사용 거리·쿨타임.
- `/gungang modify item turret damage 10`처럼 게임 안에서도 변경할 수 있습니다.
- 체력·탄약 용량·재장전 거리는 새로 설치하는 터렛에 적용됩니다. 쿨타임은 장비를 새로 지급할 때 적용됩니다.

## 모델

사용자가 제공한 `iron-nest_ver_2.0.zip`의 IRON-NEST Ver 2.0을 Forge OBJ로 변환했습니다. 본체와 포탑은 분리되어 포탑만 표적 방향으로 회전합니다. 원본 비율을 유지하면서 모든 회전이 설치 판정 2×2×2 안에 들어오도록 축소했습니다. 모델의 외형 높이와 설치 판정 높이는 다를 수 있습니다. 원본 보행 애니메이션은 고정 설치형 터렛에 사용하지 않습니다.

원본 케이블 장식 메시에는 다른 부품과 배율·바인드 좌표가 다른 문제가 있어 공중에 분리되는 해당 장식만 제외했습니다. 본체·다리 6개·포탑·포신과 원본 텍스처는 유지했습니다. 변환 스크립트는 `scripts/import_turret_model.py`입니다.
