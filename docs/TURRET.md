# 터렛 (보조무기 ID 90)

터렛은 빈 **2×2×2블록 공간**에 설치하는 자동 사격 장비입니다. 보조무기 사용 후 우클릭으로 설치하고 좌클릭으로 취소합니다. 네 바닥 블록 모두 윗면이 단단해야 하며, 물속·공중·천장이 낮은 곳·다른 개체와 겹치는 곳에는 설치할 수 없습니다. 바닥이 제거되면 터렛도 철거됩니다.

| 항목 | 기본값 |
| --- | --- |
| 쿨타임 | 터렛 파괴부터 120초 |
| 감지 반경 | 16블록 |
| 표적 | 시야가 확보된 가장 가까운 적 플레이어 또는 봇 |
| 피해 | 발당 6, 넉백 없음, 방어구·방패 등 기존 피해 규칙 적용 |
| 명중 확률 | 발당 100%, 히트스캔으로 발사 즉시 판정 |
| 발사 간격 | 4틱(0.2초), 정상 20 TPS에서 초당 5발 |
| 탄약 | 120발 |
| 체력 | 150 |
| 최대 설치 | 설치자당 1개 |
| 재장전 | 설치자만, 외곽에서 3블록 이내, 왼손 사용 후 복귀 키(기본 H) 유지, 초당 20발 |
| 수리 | 설치자만, 같은 거리에서 왼손 공격 후 복귀 키(기본 G) 유지, 1틱당 체력 1 |

적이 벽이나 다른 개체에 가려지면 사격하지 않습니다. 아군·설치자·관전자·크리에이티브 플레이어·비무장 지대와 보호 중인 대상은 공격하지 않습니다. 준비 중인 경기에서도 사격하지 않습니다. 처치와 피해량은 설치자에게 귀속됩니다.

탄약이 0이 되어도 터렛은 남으며, 본체 위로 회색 연기가 계속 발생해 탄약 소진 상태를 알립니다. 재장전으로 1발 이상 채워지면 새 연기 발생이 멈추고 남은 연기는 자연스럽게 사라집니다. 일부만 소모했을 때도 장전할 수 있습니다. 재장전·수리 중에는 사격이 멈추며, 키를 놓거나 거리가 멀어지거나 벽에 가려지거나 화면을 열면 작업이 중단됩니다. 탄약과 체력은 최대치를 넘지 않습니다. 별도 탄약 아이템은 필요 없습니다. 0발부터 완충까지 6초입니다.

설치자에게 `터렛 탄약 120/120` 보조 체력바가 표시되고, 0발일 때도 표시됩니다. 가까이 가면 탄약·체력과 재장전·수리 키 안내가 나타납니다. 키를 재지정하면 왼손 사용/공격 후 복귀 키 설정을 따릅니다.

설치한 팀 색상의 마커가 본체 위에 나타나며, 설치자에게만 터렛 발광 윤곽이 보입니다. 사격에는 전용 총성을 사용합니다. 체력이 소진되어 파괴되면 폭발음·연기·파편 효과가 발생하지만 주변 피해나 블록 파괴는 없습니다. 경기 정리 등 일반 철거에는 폭발 효과가 없습니다.

설치자 사망과 부활 대기 중에도 터렛은 유지됩니다. 보조무기 변경, 경기 정리, 청크 언로드 시 철거됩니다. 설치 시에는 쿨타임이 시작되지 않으며, 체력이 소진되어 파괴된 시점부터 120초를 셉니다. 서버 재시작 후 설치물은 복원하지 않습니다. 봇은 공격 대상에 포함되지만, 터렛의 자동 선택·설치·재장전 AI는 제공하지 않습니다.

## 설정

신규 서버 또는 `/gungang reload` 시 없는 파일을 생성합니다. 기존 ID 90 사용자 정의 무기를 덮어쓰지 않으므로 이미 해당 ID가 있으면 제공된 예제와 비교해 교체하세요.

- `config/gungang/server/sub_weapons/90_turret.json`: 보조무기 등록·설명.
- `config/gungang/item/turret.json`: 피해·감지 반경·체력·탄약·발사 간격·재장전 속도·사용 거리·쿨타임.
- `/gungang modify item turret damage 6`처럼 게임 안에서도 변경할 수 있습니다.
- 이전 배포 기본 설정과 완전히 일치하는 아이템 설정은 새 기본값으로 자동 갱신합니다. 사용자 지정 설정은 유지합니다.
- 체력·탄약 용량·재장전 거리는 새로 설치하는 터렛에 적용됩니다. 쿨타임은 파괴 시점의 설정을 적용합니다.

## 모델

사용자가 제공한 `turret.zip`의 "Turret" 모델을 Forge OBJ로 변환했습니다. 고정부(바닥판·기둥·회전 링)와 회전부(요크·총몸·포신)를 분리해 회전부만 표적 방향으로 돌아갑니다. 포신 끝까지 설치 판정 2×2블록 안에 들어오도록 축소했으며, 외형 높이는 약 1.48블록, 사격 시작점은 포신 높이인 약 1.19블록입니다. 삼각형은 합계 782개로, 여러 대가 보여도 렌더링 부담이 작습니다.

기본 색상 텍스처만 사용하고 발광·노멀 등 PBR 맵은 적용하지 않습니다. 변환 스크립트는 `scripts/import_turret_model.py`이며 원본은 `models/turret/`에 보관합니다.
