# 봇 위험물 탐색 성능 검증

2026-10-23에 로컬 Forge 1.20.1 서버에서 위험물 탐색 주기 변경을 비교했습니다.

## 재현 방법

```powershell
.\gradlew.bat runServer -PgungangBotSmoke --console=plain
```

기존 봇 서버 통합 테스트에 측정이 포함되어 있습니다. 결과는 `build/bot-smoke-run/hazard-benchmark.md`와 서버 로그의 `BOT_HAZARD_BENCHMARK_PASS`에 기록됩니다. 전체 통합 검증 성공은 `GUNGANG_BOT_SMOKE_PASS`로 별도 확인합니다. 테스트 전용 서버의 기존 설정에 설치하지 않은 모드의 무기가 남아 있으면 해당 테스트 설정을 정리해야 합니다.

## 측정 범위

- 같은 위치에 놓인 독립적인 인지 상태 4개로 봇 4명분의 탐색 호출을 수행합니다. 실제로 이동하는 봇 4명의 전체 부하를 측정한 것은 아닙니다.
- 폭격 표식 0·64·256개를 배치합니다. 최대 8개는 8블록 거리에, 나머지는 50~79블록 거리에 둡니다. 장면과 엔티티는 측정 중 고정합니다.
- 비교군은 매 판단마다 96블록을 탐색하도록 현재 코드를 호출합니다. 변경군은 `thinkTicks=5`에 해당하는 간격으로 호출해 네 번 중 한 번 광역 탐색을 수행합니다. 이전 버전의 바이너리를 직접 비교하지는 않습니다.
- 두 경로를 워밍업하고 측정 순서를 번갈아 7회 실행합니다. 회당 인지 상태별 200회, 총 800회 호출의 평균 시간을 구한 뒤 7회 중앙값을 비교합니다.
- 위험물 기억 정리와 리플렉션 호출 비용을 포함합니다. 청크 로딩·엔티티 생성·엔티티 틱·이동 AI·네트워크 비용은 제외합니다. 실제 서버 TPS 개선율로 해석하면 안 됩니다.

## 첫 실행 결과

단위는 봇 한 명의 판단 1회당 마이크로초입니다.

| 폭격 표식 수 | 매번 광역 탐색 | 주기를 분리한 탐색 | 감소율 |
| --- | ---: | ---: | ---: |
| 0 | 0.890 | 0.867 | 2.6% |
| 64 | 6.372 | 4.691 | 26.4% |
| 256 | 18.724 | 14.214 | 24.1% |

## 두 번째 실행 결과

별도 JVM으로 서버를 재실행해 같은 측정을 반복했습니다.

| 폭격 표식 수 | 매번 광역 탐색 | 주기를 분리한 탐색 | 감소율 |
| --- | ---: | ---: | ---: |
| 0 | 1.007 | 0.941 | 6.6% |
| 64 | 6.140 | 5.919 | 3.6% |
| 256 | 16.641 | 13.214 | 20.6% |

256개 장면에서는 두 실행 모두 약 21~24% 감소했습니다. 64개 장면은 약 4~26%로 실행 간 변동이 컸으므로 일정한 개선율을 보장하는 근거로 쓰지 않습니다. 위험물이 없을 때의 작은 차이는 측정 잡음의 영향을 받을 수 있습니다. 실제 맵의 엔티티 배치, 폭격 반경, 판단 주기에 따라 결과가 달라집니다. `thinkTicks`가 20 이상이면 매 판단이 광역 탐색이므로 같은 감소를 기대할 수 없습니다.

## 동작 회귀 검증

광역 탐색 사이에도 가까운 폭격을 발견하고, 제거된 위험물을 잊는지 검증합니다. 폭격 반경을 최대 허용값인 64블록으로 바꿔도 60블록 떨어진 폭격이 봇을 덮으면 즉시 다음 판단에서 발견하는지 추가로 확인합니다. 먼 폭격 표식의 최초 발견은 다음 광역 탐색까지 지연될 수 있습니다.
