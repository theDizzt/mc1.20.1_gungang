# 누적 전적·경험치·레벨

통산 승리는 DB의 `wins`에 기록됩니다. 승리팀 참가자만 경기당 1승이 증가하며 패배·무승부·중단은 증가하지 않습니다. `/gungang stats`에 승리 횟수도 표시하고, 관리자는 `/gungang stats set <플레이어> wins <값>`으로 수정할 수 있습니다. 이전 DB에 `wins`가 없으면 0으로 읽으며 기존 전적은 유지합니다. 이전 경기의 승리 횟수를 자동으로 추정하지는 않습니다.

서버가 `config/gungang/player-db.json`을 자동 생성합니다. 별도 DB 서버가 필요 없는 UUID 기반 로컬 JSON 데이터베이스입니다. 닉네임이 바뀌어도 UUID가 같으면 기록을 유지합니다. 저장은 임시 파일을 통한 교체 방식이며 직전 데이터는 `player-db.json.bak`에 보관합니다. 손상된 DB를 빈 파일로 덮어쓰지 않습니다.

경기 종료 시 누적 경험치, 경기 참여 수, 킬, 데스, 딜량, 경기 플레이 시간(초)을 저장합니다. 경기 중 퇴장한 참가자도 포함하고 관전자는 제외합니다. `/gungang stop`과 정상 서버 종료는 진행한 전적을 저장하되 경험치를 지급하지 않습니다. 서버가 비정상 종료되면 종료하지 못한 경기의 전적은 저장되지 않습니다. 로비 대기 시간은 플레이 시간에 포함하지 않습니다.

## 명령어

| 명령어 | 기능 |
|---|---|
| `/gungang stats [플레이어]` | 전적·경험치·레벨 조회 |
| `/gungang xp [플레이어]` | 현재 레벨의 경험치/다음 레벨까지 필요한 경험치 조회 |
| `/gungang level [플레이어]` | 레벨·경험치 조회 |
| `/gungang stats set <플레이어> <필드> <값>` | 관리자: 전적 또는 XP 수정 |
| `/gungang xp set <플레이어> <값>` | 관리자: 누적 경험치 지정 |
| `/gungang xp add <플레이어> <값>` | 관리자: 경험치 가감(최종값은 0 이상) |

조회 시 이름 생략은 본인입니다. DB에 있는 오프라인 플레이어는 이름 또는 UUID로 지정할 수 있습니다. 수정 필드는 `xp`, `matches`, `kills`, `deaths`, `damage`, `playSeconds`입니다. 예: `/gungang stats set dizzt3942 kills 100`. 전적 변경이 경험치를 자동 재계산하지는 않습니다. XP 변경은 접속자의 HUD에 즉시 반영됩니다. 수정 명령은 OP 권한 레벨 2 이상이 필요합니다.

조회 결과는 `sendCommandFeedback`가 꺼져 있어도 명령 실행자의 채팅에 표시됩니다. `stats`, `xp`, `level`의 경험치는 현재 레벨 구간 기준으로 표시합니다. 예를 들어 누적 XP 141인 2레벨은 `경험치 60/120`이며, 최고 레벨은 `경험치 MAX`입니다.

## 경험치 보상

`config/gungang/server/option.json`:

```json
"experience": {
  "winBase": 32,
  "winContributionMax": 24,
  "lossBase": 16,
  "lossContributionMax": 16,
  "killWeight": 1.0,
  "assistWeight": 0.5,
  "damagePerPoint": 100.0
}
```

개인 기여 점수 = 킬 × killWeight + 어시스트 × assistWeight + 딜량 ÷ damagePerPoint.
추가 XP = 기여도 최대 보상 × (개인 기여 점수 ÷ 같은 팀 전체 기여 점수), 소수점 버림.
팀 기여 점수가 0이면 추가 보상은 0입니다. 승리팀은 기본 32~56 XP, 패배팀은 16~32 XP를 받습니다. 무승부는 패배팀과 같은 보상 규칙을 적용합니다. 쟁탈전·노르망디·팀 데스매치에 공통 적용합니다.

## 레벨 요구 경험치

`config/gungang/xp.json`의 `cumulativeXp` 배열은 **91개 누적 경험치**입니다. 1레벨은 0, 2레벨은 81, 3레벨은 201, 마지막 91레벨은 267909이며 제공받은 전체 누적표를 기본값으로 사용합니다. 첫 값은 0이고 이후 값은 엄격히 증가해야 합니다. 누적 XP는 레벨업해도 차감되지 않습니다. 예를 들어 2레벨에서 XP가 141이면 현재 구간은 (141−81)/(201−81)=50%입니다.

레벨은 1~91입니다. 91레벨 이후에도 누적 XP는 저장되고 HUD 바는 가득 찬 상태를 유지합니다. 필요 경험치 표를 바꾸면 기존 누적 XP를 기준으로 레벨이 다시 계산됩니다. 로비에서 `/gungang reload`를 실행하면 적용됩니다.

커스텀 HUD는 이름 위에 레벨 숫자와 흰색 경험치 바를 표시합니다. 바는 해당 레벨 구간에서 다음 레벨까지의 진행률입니다. 서버와 클라이언트 모두 최신 모드를 사용해야 합니다.
