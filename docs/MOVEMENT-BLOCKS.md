# 이동 블록 (u138)

- `gungang:conveyor_belt`: 위·아래 반블록 설치. 두 개를 합쳐 이중 반블록으로 만들 수 없다. 같은 높이의 벨트가 레일처럼 직선 또는 좌우 코너로 연결된다. 각 블록의 연결 포트는 두 개이며 분기점에서는 기존 연결을 우선한다. 경사는 지원하지 않는다.
- `gungang:wrench`: 벨트를 우클릭해 설정창을 연다. 속도는 0.1~3.0배속, 0.1 단위다. 1.0배속은 초당 2블록이다. 현재 진행 방향 유지 또는 반전을 선택하고 적용하면 양방향으로 연결된 전체 경로에 적용한다. 닫힌 순환 경로도 지원한다. 상단 화살표가 진행 방향을 표시한다.
- 설정은 월드에 저장되고 클라이언트와 동기화된다. 연결 경로의 청크가 로드되지 않았거나 4,096개를 넘으면 일부만 변경하지 않고 안내를 표시한다. 서로 옆에 있어도 연결 포트가 맞지 않는 벨트는 별개다.
- 벨트 위 플레이어·몹·떨어진 아이템을 이동시킨다. 점프하거나 날고 있을 때는 밀지 않는다.
- `gungang:blue_jump_pad`: 점프 발판 표면에서 점프하면 발판 표면보다 8블록 높이까지 상승한다.
- `gungang:lime_jump_pad`: 같은 방식으로 16블록 상승한다. 천장이 있으면 충돌하며, 중력/이동을 바꾸는 외부 효과는 높이에 영향을 줄 수 있다.
- 발판은 2픽셀 두께다. 같은 색을 같은 높이에 붙이면 내부 테두리가 사라지고 에너지 격자 텍스처가 이어진다. 형광색 하드라이트 입자가 위로 올라온다. 발판으로 도약한 뒤 첫 착지에는 낙하 피해가 없다.
- 건갱 블록/아이템 크리에이티브 탭, `/give`, 추가 제작법으로 획득할 수 있다.

리소스 재생성: `powershell -ExecutionPolicy Bypass -File scripts/make_motion_resources.ps1`.
회귀 검증: `gradlew.bat test`, 격리 월드 검증: `gradlew.bat -PgungangMotionSmoke runServer`.

2026-10-28 검증: JUnit 243개 통과. 전용 테스트 서버에서 자동 코너 연결, 전체 경로 양방향 전환, 속도 저장 복원, 0.1/1.0/3.0배속의 코너 통과, 중복 이동 방지, 실제 생명체 이동 물리의 8/16블록 최고 높이를 확인했다. 클라이언트에서는 56개 블록 상태의 모델/텍스처 로딩과 설정창 렌더링을 확인했다. 캡처는 `build/ui-smoke/movement-blocks.png`, `build/ui-smoke/conveyor-settings.png`에 저장된다. 실제 두 클라이언트의 동시 탑승은 자동 검증 범위에 포함되지 않는다.
