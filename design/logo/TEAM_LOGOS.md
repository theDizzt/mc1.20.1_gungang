# 팀 로고

- 원본: `alpha.png`, `bravo.png`
- 투명 배경 버전: `alpha-transparent.png`, `bravo-transparent.png`
- 게임 리소스: `src/main/resources/assets/gungang/textures/team/`

외곽 검은 배경을 투명하게 처리했다. 문양 내부의 어두운 방패 바탕은 로고의 일부로 유지했다. 원본은 보존한다.

로고 자체는 알파의 금색과 브라보의 보라색을 유지한다. 설정 가능한 팀 색상은 HUD 바, 미니맵 테두리, 깃발 천과 효과 범위에 별도로 사용한다. 로고는 색상 비교가 아닌 팀 이름(ALPHA/Red, BRAVO/Blue)으로 선택한다.

적용 위치:

- 경기 점수 HUD(팀전·폭탄전·점령전), 호위전 HUD
- TAB 팀 카드, 로비 팀 제목
- 일반 지도 미리보기의 팀 스폰과 범례
- 폭탄전 미니맵과 지도 제작대의 서버 제공 플레이어 표식
- 지휘 깃발 양면의 문양, 방벽 양면, 터렛의 받침
- 아군에게 표시되는 지뢰와 베어트랩의 윗면

폭탄전 지도 스폰은 공수 교대에 따라 팀이 바뀌므로 역할 기준의 원형 표시를 유지한다. 미니맵에는 서버가 제공한 위치만 표시한다. 지뢰·덫 로고는 기존 아군 표시 조건을 따른다.

지도 미리보기 형식 버전을 변경하여 저장된 자동 생성 지도 캐시가 갱신되도록 했다.
