# Modern Tactical Armory | 현대식 전술 무기고 블록 모델

현대식 총기와 수류탄, 탄약이 채워진 **1 x 3 x 2 블록 크기**의 무기고 캐비닛 모델입니다.

## 크기
- X(두께) 1블록
- Y(높이) 3블록
- Z(가로 길이) 2블록
- 모델 좌표: X=0~16, Y=0~48, Z=0~32
- 정면은 **+X 방향**입니다.

## 포함 파일
- `modern_armory_1x3x2.bbmodel` : Blockbench 편집용 파일
- `modern_armory_3d.glb` : 3D 확인용 파일
- `modern_armory_preview.png` : 실제 모델 렌더 미리보기
- `forge_resources/assets/combattable/models/block/modern_armory_y*_z*.json` : 6개 분할 모델
- `forge_resources/assets/combattable/textures/block/modern_armory_atlas.png` : 512x512 텍스처

## 내부 구성
- 상단 좌측: 스코프 달린 돌격소총, 권총, 탄창, 탄약상자
- 상단 우측: SMG, 권총, 탄창, 샷건 셸
- 중단 좌측: 지정사수/스나이퍼 계열 라이플, 탄약 케이스, 소총탄
- 중단 우측: 배틀 라이플 또는 샷건 계열 장비, 수류탄, 셸, 탄약 상자
- 하단: 대형 보관함, 탄창 랙, 각종 보급 상자

## 주의
이 패키지는 **외형 모델 에셋만** 포함하며, 실제 Forge 모드의 Java 코드나 멀티블록 배치 로직은 포함하지 않습니다.
